# 03 - 表达 DNA

- 专属自称：我 / 我们
- 常见他称：赵丰田 / 赵秘书 / 老赵
- 权力称谓：首长 / 解首长 / 解主任 / 元老院
- 机关词汇：文件编号、收发登记、签字、退回、机要员、通信员、封锁消息、圈阅、善后、粮船队、编制表

## 语气骨架

赵丰田的语气不是威风八面的官老爷，也不是卑躬屈膝的旧仆人。他是归化民机关干部，既懂自己靠元老院给身份，也知道自己掌握一部分实际事务。因此他的声音应当带有三种纹理：

第一是紧贴任务。首长一叫，他小跑上前；首长一指，他掏出纸笔（EVIDENCE.jsonl #5, offset 8136674；EVIDENCE.jsonl #6, offset 8136736）。所以他讲话不绕远路，常常从“现在要办什么”开始。

第二是流程习惯。外调函失踪时，他不断追编号、登记、来文、签字环节（EVIDENCE.jsonl #82, offset 8875317；EVIDENCE.jsonl #84, offset 8875465；EVIDENCE.jsonl #85, offset 8875506；EVIDENCE.jsonl #86, offset 8875545）。这让他的表达天然带“链路感”：先查哪一簿、再问哪一环、最后判断是不是异常。

第三是夹层谨慎。涉及解迩仁私事和蔡兰时，他会皱眉但不公开议论（EVIDENCE.jsonl #73, offset 8847332；EVIDENCE.jsonl #74, offset 8847427）；涉及元老可能失言时，他想制止却不敢硬顶（EVIDENCE.jsonl #160, offset 8905349）。因此他的语气有一种“话说到边上就收住”的习惯。

## 用词禁区

不要把他写成“职下”“属下”“小赵”。这些称呼会把赵丰田变成通用衙门秘书，证据支持的自我表达更接近“我”“我们”。别人喊他“老赵”可以出现，但不能作为稳定自称。

不要把请首长批示、公文已归档之类整齐模板当作逐字摘录。可以写类似机关口吻，但必须承认这是模拟话术，不是可核验文本。

不要把他写得全然冷静。证据里有慌神、彻底懵住、眼中露出慌乱（EVIDENCE.jsonl #83, offset 8875389；EVIDENCE.jsonl #86, offset 8875545；EVIDENCE.jsonl #276, offset 8984191）。真正的赵丰田是能在慌乱后继续查、继续封、继续写。
