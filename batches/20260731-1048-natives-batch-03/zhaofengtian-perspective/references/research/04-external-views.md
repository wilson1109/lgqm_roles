# 04 - 外部视角

赵丰田不是靠旁白夸成“能臣”的人物，他的地位来自多个外部视角的交叉：解迩仁需要他，骆阳明依赖他，机关人员接受他的调度，调查者能从他的从容中看出破绽。

## 解迩仁视角：左膀右臂，也嫌他啰嗦

梧州归化民干部极少，旁白明确把赵丰田和钱多列为解迩仁视为左膀右臂的一文一武（EVIDENCE.jsonl #12, offset 8160192）。这说明在地方政权初建阶段，赵丰田不是可有可无的文员，而是解迩仁治理能力的延伸。

但解迩仁并非总喜欢他的提醒。后文提到解迩仁嫌赵丰田啰嗦，换过一个更会揣摩心意的秘书（EVIDENCE.jsonl #37, offset 8194540）。这条证据很重要：赵丰田的价值恰恰不在“善解人意”，而在会指出不合适、会打断首长发散、会把事情拉回流程。

## 骆阳明视角：本地事务中的协作对象

骆阳明与赵丰田的关系显示赵丰田已是市办关键入口。骆阳明为了易浩然外调问题反复去赵丰田那里查回复（EVIDENCE.jsonl #77, offset 8874527）；粮食保卫计划也由赵丰田拿给他看，并请他从本地人角度找漏洞（EVIDENCE.jsonl #71, offset 8846744）。赵丰田对骆阳明既不摆首长秘书的架子，也不完全放权。他让骆阳明参与判断，但文件仍要送解主任圈阅。

骆阳明能感受到赵丰田对解迩仁沉溺女色的忧虑和反感，却也知道归化民干部不会公开议论首长（EVIDENCE.jsonl #73, offset 8847332）。这说明外部人眼中的赵丰田并非麻木，而是压抑。

## 机关下属视角：能下命令的市办节点

赵丰田能调机要员查簿册，能通知郑二根抓人，能和警卫秘书合计封锁院落（EVIDENCE.jsonl #79, offset 8874978；EVIDENCE.jsonl #84, offset 8875465；EVIDENCE.jsonl #101, offset 8879324）。解迩仁被擒后，他还可以向朱大队长提出侦缉队和赏格安排（EVIDENCE.jsonl #122, offset 8892169）。这些动作显示他不是纸面秘书，而是机关实际节点。

这种节点地位有风险：他越能调度，越容易被卷入遮掩。后续报告口径和三合嘴甩锅说明，他不是旁观者（EVIDENCE.jsonl #195, offset 8912587；EVIDENCE.jsonl #201, offset 8913454；EVIDENCE.jsonl #224, offset 8921601）。

## 调查者视角：从容中有裂缝

听证相关讯问中，赵丰田态度从容，一五一十回答（EVIDENCE.jsonl #269, offset 8983379）。这符合他长期机关训练和秘书经验。但当问到外调函是否发出时，他露出一丝慌乱，被陈白宾和姬信捕捉到（EVIDENCE.jsonl #276, offset 8984191）。随后他解释拟稿、领导签字、收发部门发出的流程（EVIDENCE.jsonl #277, offset 8984266）。

外部调查者看到的不是“恶人露馅”，而是一个熟悉流程的人在流程断点前失去了一瞬间稳定。这是赵丰田最真实的裂缝。
