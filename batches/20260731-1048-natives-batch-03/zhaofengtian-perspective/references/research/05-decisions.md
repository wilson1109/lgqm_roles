# 05 - 关键决策研究

## 决策一：提醒归降官吏优先于宣传队

场景：梧州初建政务，解迩仁要求立刻拉宣传队（EVIDENCE.jsonl #13, offset 8161399）。赵丰田提醒外面归降官吏已经等了大半天（EVIDENCE.jsonl #14, offset 8161478）。

判断：赵丰田能识别行政接管中的优先级。宣传重要，但投降官吏涉及政权交接、地方秩序和职位安排，更不能拖太久。他的提醒不是反宣传，而是把首长注意力拉回“今天必须见的人”。

## 决策二：不赞成三总府关防转移

场景：三总府地方大、机构多、军队复杂。赵丰田认为那里不利于严密关防（EVIDENCE.jsonl #58, offset 8838092）。

判断：他不是只会执行。面对首长身边安全和机关保密，他会从空间、驻军成分和关防强度判断风险。这个判断后来被蔡兰与外调函事件反向证明：首长私事与机关空间混杂，会直接破坏流程和保密。

## 决策三：外调函从源头查

场景：易浩然外调函没有回复，骆阳明认为不合流程。赵丰田先安抚，再承诺粮食入库后从源头查（EVIDENCE.jsonl #77, offset 8874527；EVIDENCE.jsonl #78, offset 8874623）。后来越想越可疑，立刻调公文簿册核对（EVIDENCE.jsonl #80, offset 8875021；EVIDENCE.jsonl #81, offset 8875124）。

判断：他的流程意识不是装饰。文件有编号就要有下落；藤县即便无法调查，也应有回复。赵丰田把“没有回复”识别为链路断裂，而不是普通忙乱。

## 决策四：先控郝冉和蔡兰院落

场景：骆阳明对郝冉没有充分罪证，但强烈不放心。赵丰田决定通知郑二根抓人（EVIDENCE.jsonl #79, offset 8874978）。调查蔡兰时，赵丰田与警卫秘书、郑二根合计封锁院落、回收文件、封锁消息（EVIDENCE.jsonl #101, offset 8879324）。

判断：赵丰田不是法理优先型。他承认证据不足不宜下结论（EVIDENCE.jsonl #92, offset 8878009），但愿意先做控制措施。这是乱世行政的灰色手段：定罪要等，控制不能等。

## 决策五：解迩仁被擒后迅速悬赏追踪

场景：枪响后解迩仁被擒。赵丰田判断时间短、敌人跑不远（EVIDENCE.jsonl #120, offset 8892065），要求侦缉队全体出动，并用不同赏格寻找敌踪、解首长踪迹和救回解首长（EVIDENCE.jsonl #122, offset 8892169）。

判断：赵丰田把危机拆成可执行任务：人员、线索、奖励、时间窗口。他不是战斗指挥官，但能用市办资源和本地侦缉体系弥补军方反应空白。

## 决策六：善后口径与甩锅三合嘴

场景：夜袭后，赵丰田预判解迩仁会隐瞒失败（EVIDENCE.jsonl #150, offset 8903862）。他在报告中把主因压到守备力量弱小（EVIDENCE.jsonl #195, offset 8912587），把留用人员伤亡从主要统计中拿掉（EVIDENCE.jsonl #201, offset 8913454），后来把三合嘴贪腐案定为调查重点，以转移视线（EVIDENCE.jsonl #224, offset 8921601）。

判断：这是赵丰田最不光彩也最能显示能力的决策。他知道上级需要一个能处分、能解释、能结束的故事。他参与构造这个故事，代价是事实被压扁。

## 决策七：给相关人员银子让她们离开

场景：事后他承认亏心（EVIDENCE.jsonl #229, offset 8935215），却又拿出银子，让两名相关人员尽快与家人离开梧州（EVIDENCE.jsonl #232, offset 8935537）。

判断：赵丰田选择的不是公开纠错，也不是血腥灭口，而是迁离。它兼具补偿、封口和排险功能。这正是他的污手良心：想留一点人情，又要确保后患不回到市办。
