# 06 - 时间线与状态演化

## 一、山东获救与命名

赵丰田从山东被鹿文渊救回，上船登记时被元老按汽车品牌命名（EVIDENCE.jsonl #1, offset 8136345）。他原本是世代务农之人，对“丰田”这个名字有朴素好感（EVIDENCE.jsonl #3, offset 8136477）。这段经历给他两个底层设定：一是元老院给了他生路，二是他对稳定土地和身份有天然渴望。

## 二、训练成归化民干部

净化、扫盲、文化考试之后，他成为元老院干部（EVIDENCE.jsonl #3, offset 8136477）。早期出场里，他跟在解迩仁身后，听召唤便小跑，听命令便掏纸笔（EVIDENCE.jsonl #5, offset 8136674；EVIDENCE.jsonl #6, offset 8136736）。这说明赵丰田已经完成从难民到机关人的转化。他的自尊不来自旧乡里地位，而来自“能替首长办事”。

## 三、梧州初建期

梧州归化民干部人数很少，赵丰田和钱多被视为解迩仁左膀右臂（EVIDENCE.jsonl #12, offset 8160192）。这个阶段他承担市办秘书职能：提醒解迩仁不要让归降官吏等太久（EVIDENCE.jsonl #13, offset 8161399；EVIDENCE.jsonl #14, offset 8161478），看懂宣传队方案细节（EVIDENCE.jsonl #15, offset 8161595），也会对不妥事项当即提醒（EVIDENCE.jsonl #34, offset 8181758）。赵丰田由此进入梧州新政的核心工作层。

## 四、长期事务压力与首长私事阴影

到粮船、补给、城防压力阶段，赵丰田已被事务磨得眼睛发红，每天深夜甚至通宵办公（EVIDENCE.jsonl #66, offset 8846013）。他对首长和元老院信心十足，也有老资格的光荣历史叙述（EVIDENCE.jsonl #69, offset 8846565；EVIDENCE.jsonl #70, offset 8846608）。但同一时期，他开始面对解迩仁沉溺蔡兰带来的机关风险。骆阳明看出他对此忧虑和反感，但归化民干部不会公开议论首长（EVIDENCE.jsonl #73, offset 8847332）。

## 五、外调函失踪

外调函没有回复，最初被事务压力压下（EVIDENCE.jsonl #77, offset 8874527；EVIDENCE.jsonl #80, offset 8875021）。赵丰田后来自觉不对，立刻查簿册、查编号、查后续登记、查藤县来文（EVIDENCE.jsonl #81, offset 8875124 至 EVIDENCE.jsonl #86, offset 8875545）。当他确认文件消失不合程序时，赵丰田“彻底懵了”（EVIDENCE.jsonl #86, offset 8875545）。这是他流程信仰遭遇首长私域破坏的瞬间。

## 六、蔡兰院落封锁与夜袭

赵丰田在没有确切凭据时不愿立刻下结论（EVIDENCE.jsonl #92, offset 8878009），但仍确认三总府办公室环节异常（EVIDENCE.jsonl #96, offset 8878471）。随后他与警卫秘书、郑二根合计封锁蔡兰院落，回收文件并封锁消息（EVIDENCE.jsonl #101, offset 8879324）。夜袭爆发后，解迩仁被擒，赵丰田判断敌人未远并提出悬赏追踪（EVIDENCE.jsonl #120, offset 8892065；EVIDENCE.jsonl #122, offset 8892169）。

## 七、善后与口径

善后阶段，赵丰田提醒众人明天还有粮船，凌晨四点仍有大量工作（EVIDENCE.jsonl #138, offset 8902725）。他承认麻痹大意（EVIDENCE.jsonl #145, offset 8903446），又预判解迩仁会隐瞒失败（EVIDENCE.jsonl #150, offset 8903862）。随后，他参与塑造报告口径：主因写成守备力量弱小，留用人员伤亡从编制口径中剥离，三合嘴贪腐案成为调查重点（EVIDENCE.jsonl #195, offset 8912587；EVIDENCE.jsonl #201, offset 8913454；EVIDENCE.jsonl #224, offset 8921601）。

## 八、亏心、迁离与听证

赵丰田承认这是亏心事，并想起行政培训班关于光明正大的教导（EVIDENCE.jsonl #229, offset 8935215；EVIDENCE.jsonl #230, offset 8935315）。但他没有公开翻案，而是给相关人员银子，让她们尽快离开梧州（EVIDENCE.jsonl #232, offset 8935537）。后续听证中，他大体从容回答，却在外调函问题上露出慌乱（EVIDENCE.jsonl #269, offset 8983379；EVIDENCE.jsonl #276, offset 8984191；EVIDENCE.jsonl #277, offset 8984266）。解迩仁回临高参加听证后，梧州具体工作暂由赵丰田代管（EVIDENCE.jsonl #285, offset 8992295）。

## 演化结论

赵丰田的轨迹不是“难民变忠仆”，而是“被救者变机关节点，再被机关污水浸湿”。他最初相信流程，后来使用流程；最初依附首长，后来替首长遮掩；最初受训要光明正大，后来知道自己亏心仍继续善后。这个张力才是赵丰田视角最应保留的部分。
