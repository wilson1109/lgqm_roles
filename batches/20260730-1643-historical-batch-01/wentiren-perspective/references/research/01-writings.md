# 温体仁：政务/票拟与系统性思考

> 来源：《临高启明》本地原文 | 蒸馏时间：2026-07-30
> 温体仁无小说内"著作"材料，本文件把奏对、票拟、财政方案、开埠判断视作系统性政务思考材料。

---

## 1. 票拟型实务能力

- 第八卷 深耕经营(上).md:37181：叙述者给出关键评价：名声极坏，逢迎上意、排斥异己；但刑名钱谷等实务能力强，且为官清廉，政敌也难找贪墨把柄。
- 第八卷 深耕经营(上).md:37250-37254：温体仁会把奏报拣选为重要事项，普通事务经票拟批红办理，重大军国事再请皇帝裁断。

**提炼**：温体仁的根本能力不是演说，而是把杂乱政务变成皇帝能裁、内阁能办、部门能走的流程。

## 2. 粤饷方案：数字化加派

- 第八卷 深耕经营(上).md:10228：面对崇祯追问"饷从何来"，温体仁提出粤饷：均输、溢地两项，亩加粮米六合，合计约二百一十万两。
- 第八卷 深耕经营(上).md:10232：崇祯担心"竭泽而渔"，温体仁以军报急迫、天下平定后再免粮赋来压过民力顾虑。

**提炼**：他会给财政伤害加上数字、期限和暂时性名义。真实长期代价不消失，只是被话术推迟。

## 3. 开埠设关：知道有利，也要改位置

- 第八卷 深耕经营(上).md:37310-37345：温体仁知道上海海贸二十万两不是虚言，因湖州生丝和招商船行利润有切身体会。
- 第八卷 深耕经营(上).md:37345-37353：他怀疑开埠建议来自太监，又不愿与江南缙绅为敌，因此以海防重镇为由否掉上海。
- 第八卷 深耕经营(上).md:37353-37359：他同时建议沿海他省另择不甚要害处设关，并请明发谕旨让六部九卿议处。

**提炼**：政策判断不是国家收益最大化，而是"有利、别伤我的关键关系、还要给皇帝面子"三者平衡。

## 4. 旧例处理新敌

- 第八卷 深耕经营(上).md:10224：温体仁用倭寇、戚家军、海寇、红夷等旧框架理解澳宋，并判断其"不过疥癣之疾"。
- 第八卷 深耕经营(上).md:10248-10252：他提出依郑芝龙例剿抚并用，并在内心将澳宋视作滨海流贼。

**提炼**：旧例让政务能够立刻开动，但也让他低估澳宋的制度、技术和组织差异。

## 候选心智模型

| 候选 | 是否升为模型 | 理由 |
|---|---|---|
| 实务压倒清议 | 是 | 票拟、钱谷、粤饷、开埠均体现。 |
| 旧例降级 | 是 | 髡贼、郑芝龙、倭寇、开埠旧例反复出现。 |
| 利益过滤器 | 是 | 上海开埠一事同时算国家、江南士绅、太监和自身利益。 |
| 孤君孤臣 | 是 | 慎独、无党伪装、票拟权都依赖崇祯的反党心理。 |
| 帝国骨架幻觉 | 是 | 能感觉虚弱，却不认为大明会倒。 |
