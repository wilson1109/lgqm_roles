# 06-timeline: 王企益时间线

| 阶段 | 原著事件 | 对思维的影响 |
|---|---|---|
| 旧时空 | 王企益、张筱奇都是基层税务出身，曾隐瞒职业身份，想经营小家庭。 | 税务专业来自一线，不来自宏大理论；同时形成强烈家庭取向。 |
| 临高早期 | 因在论坛谈粮赋征收专业看法被“揪出来”，进入财金口工作。 | 他从边缘混日子转入五道口技术干部序列。 |
| 广州任命 | 被任命为广东省财税副专员兼广州市财税局副局长。 | 从执行型税务干部变成地方财税制度建设者。 |
| 抵达广州 | 带 47 名干部和学员到广州，接手征收准备。 | 开始把艾志新的方案落成岗位、干部和流程。 |
| 税制调整 | 参与人头税、税务机构、代收代缴、申报征收等方案调整。 | 形成“现实妥协必须有现代流程包装”的方法。 |
| 第一次征收 | 参与大厅、税票、报表、管理档案和万元报表。 | 更确认干部培养和内控比一时效率更重要。 |
| 预算会议 | 向广州元老解释税款归中央、地方需预算分级。 | 从征管实务进入财政政治，认识中央地方拉力。 |
| 财政奥秘 | 与艾志新、张筱奇讨论财税局垂直体系和德隆国库。 | 明确财税局是中央制衡地方的纵向工具。 |
| 经济罪案调查处 | 参与方案并暂任负责人。 | 在专业文职和必要强制力之间找到低调路径。 |
| 贵人聚税案 | 圈定林、梁、史，查史家避税和假税票。 | 形成“票、账、仓库、汇款、完税证”联动查案方法。 |
| 楚小冉自杀 | 设计责任分担、舆论转化和孩子安置。 | 暴露其机关化危机处理能力，也保留同情心。 |
| 佛山和土地税 | 参与梁家田产、土地税、小元老挂职讨论。 | 把单案打击接到长期税制和治理样板。 |
| 第八卷后续 | 税案材料中仍以王局条子和财税流程作为节点。 | 说明他建立的征管和调查体系延续运作。 |

## 时间线结论

王企益的轨迹不是“突然觉醒的政治家”，而是基层税务干部在广州高压场景中被迫成长为财税制度操盘手。他的每一次变化都与具体问题相连：人手不足、税款归属、地方争钱、大户避税、假税票、归化民干部风险、女儿挂职。写他必须把家庭、机关和财政制度放在同一条线上。
