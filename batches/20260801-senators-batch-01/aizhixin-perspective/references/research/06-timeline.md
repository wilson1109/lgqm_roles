# 06-timeline: 艾志新时间线

| 阶段 | 事件 | 对思维的影响 |
|---|---|---|
| 旧时空 | 在国税局工作，爱精美物品和金领式形象。 | 形成税务机关经验、制服/窗口/票证审美和机关政治直觉。 |
| 五道口时期 | 长期负责财税工作；早期财政主要靠战利品、贸易、田赋、渔业税和有限关税。 | 知道元老院财政能力长期不足，也知道税收体系必须跟着工商业繁荣升级。 |
| 广州光复后 | 被任命为广东大区财税专员兼广州市财税局局长，进驻盐课司。 | 获得空前税权，也承受新币、专卖、税务和广东全省征管压力。 |
| 税制初设 | 研究广州府旧税资料，提出财产税、流通税、印花税三大类和“自报实缴，轻税重罚”。 | 税收从临高经验转为大城市制度建设；数据和账本成为核心。 |
| 风俗业整肃 | 参与风俗业会议，提出人头税、牌照税、黄票和紫明楼接收构想。 | 把灰色经济明朗化，把税收、卫生、治安和产业重组连起来。 |
| 数据中心到来 | 迎接冯诺、徐老五等数据/机械计算设备人员。 | 进一步确认没有数据处理能力就无法管理广州税源。 |
| 王企益抵达 | 王企益带 47 名干部到广州，批评人头税并补足征管流程。 | 艾志新从顶层设计转向放权给实务派，把税务机器真正运转起来。 |
| 张筱奇抵达 | 张筱奇改造包税方案为代收代缴，设计集中征收和申报流程。 | 艾志新学会用现代法理和程序包装现实妥协。 |
| 征税大厅开张 | 税徽、制服、窗口、口号和缴税流程落地。 | 财税局从纸面机构变成广州人可见、可怕、可依规接触的国家机器。 |
| 一季度报表 | 税收统计报表引发广州元老预算争夺。 | 税收不只是技术工作，而是地方财政政治的核心筹码。 |
| 经济罪案调查处 | 推动财税局二级执法机构成立，处理印花税案、假税票和经济重案。 | 财税从征收到监管、打击和资产保全扩展。 |
| 贵人聚/税案 | 楚小冉自杀、罗林史梁案和假税票线索推动财税局主动争主责。 | 形成“钱的事，我们管”的办案边界。 |
| 土地税/房产税 | 从梁家田产切入，推动城镇土地税、房产税和增值税兜底。 | 财税工具成为套住旧豪强根基的绳索。 |
| 南洋公司/广交所 | 参与融资审核，主张证券印花税先设条目、暂缓征收。 | 在市场初创期懂得先养鱼后收税。 |
| 小元老挂职 | 讨论佛山挂职和财税局工作压力，直言元老席位世袭。 | 暴露其元老院统治阶层意识和组织利益本能。 |

## 材料边界

艾志新的高密度材料集中在第七卷广州治理篇；两广攻略篇补充其财金会议、解迩仁备忘录和南洋公司融资场景；第八卷只留下流程性余波。没有发现可独立支撑早年详细履历的原著段落。
