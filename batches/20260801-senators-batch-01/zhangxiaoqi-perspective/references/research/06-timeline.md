# 06-timeline: 张筱奇时间线

| 阶段 | 原著事件 | 对思维的影响 |
|---|---|---|
| 旧时空 | 张筱奇与王企益都是基层税务出身。 | 形成重流程、重申报、重窗口、重处罚依据的实务底色。 |
| 临高早期 | 夫妻二人隐瞒职业身份，后因王企益专业发言被挖到财金口。 | 她并非天然权力追求者，专业身份是被现实需要推出来的。 |
| 广州任命 | 被任命为广东省财税调研员兼广州市财税局调研员。 | 起初受家庭牵挂影响，但被征收实务需要吸到核心位置。 |
| 包税危机 | 艾志新方案在元老院被骂，她提出代收代缴替代。 | 形成“现实妥协必须换现代名义”的代表模型。 |
| 征收准备 | 坚持集中征收、申报、零申报、德隆代收远景和大厅警力。 | 把税法程序、现金内控和女性干部保护合为一体。 |
| 第一次征收 | 培训大厅人员和会计人员，经历报表调平挫折。 | 从旧时空经验转向新时空人工系统，认识干部培养的重要性。 |
| 财政分成 | 与王企益在广州元老会议上讲国地税和税收共享。 | 从税务征管扩展到财政制度和中央地方政治。 |
| 自行申报 | 推动大户财务负责人、复式记账和抓大控中定小。 | 把纳税人本身纳入现代会计训练。 |
| 融资会议 | 给张允幂讲机关政治，分析南洋公司税目。 | 展现对报告政治、地方利益和金融征税的综合判断。 |
| 经济罪案 | 参与经济罪案调查处方案和候选人讨论。 | 对扩权保持现实敏感，不只看专业必要性。 |
| 楚小冉事件 | 发现遗物、参与善后、提醒隔离制度和口径冲突。 | 女性同情、纪律责任和旧伦理冲突集中爆发。 |
| 林家处罚 | 用处罚条例、暂存款和虚假申报设计处理林家。 | 完成从流程专家到制度杀伐者的转化。 |
| 佛山挂职 | 担心王慕清去佛山，后被王企益拖延。 | 母亲身份和元老院组织利益发生冲突。 |

## 时间线结论

张筱奇的成长线不是“从柔到刚”，而是一直同时保有柔与刚。她对女儿、女干部和张允幂有保护欲；对大户、偷漏税和空泛人性化却毫不留情。她的财税视角越往后越宽，从窗口流程扩展到财政分成、金融商品、土地税和元老院舆论。
