# 李默：人物时间线

> 来源：《临高启明》本地原文 | 蒸馏时间：2026-07-30

| 时间/阶段 | 事件 | 对人物的影响 |
|---|---|---|
| 早年澳门/广州 | 出身广州/澳门海商大户奴婢家庭；原文对籍贯/旧居有“南海县”和“香山县恭常都”两处表述。她与李丝雅、李淳形成乳姐妹/主从混合关系。 | 旧主从秩序成为后来面对李丝雅时的心理底色；籍贯细节需按锚点写。 |
| 十八岁左右 | 受海盗“掌柜”诱骗私奔，漂泊后生下李荃，被安置到临高苟家庄。 | 私奔成为羞耻和愧疚来源，也让她与原家庭断裂。 |
| D日前后 | 丈夫死后失去供养，在苟家庄受欺凌，带女儿几近饿死，被张兴教收容。 | 澳宋和初晴的帮助在她心里形成强恩情。 |
| 南海农庄阶段 | 在吴南海羽翼下生活，少说话，保护李荃，避开计启立等外部男性。 | 形成“低可见度+庇护换安全”的生活方式。 |
| 转入卫生系统 | 接受护理培训但学医吃力，转做总务，能写能算，逐渐成为“李大姐”。 | 后台事务成为她的能力位置。 |
| 广州巡诊前 | 被派往紫诚记打前站，负责药品器械归置。 | 能独立承担外地巡诊后勤。 |
| 1632年广州巡诊 | 收到紫丁香绦结后秘密赴紫明楼，与李丝雅重逢，恢复通信渠道。 | 旧关系重新接入她的澳宋生活。 |
| 1632年调查 | 巡诊队告密引发柯云调查；紫明楼行踪可疑但无决定性证据，李默和李荃被开检监控。 | 从高鉴定归化民干部转入长期风险观察。 |
| 李华梅入籍后 | 李华梅在临高寻找李默失败；李默两点一线，几乎不在普通归化民生活中出现。 | 她的低可见度客观上维持了姐妹隔离。 |
| 两李专案 | 政保发现李默与李丝雅通信，推断李默和李华梅是亲姐妹，准备切断联系。 | 她从“可疑个体”升级为李丝雅网络节点。 |
| 岗位转移 | 李默被调到南海示范农场模范兽医站任庶务长。 | 被移出元老核心医疗安全位置，但留在临高和农业口附近。 |
| 省港总医院后期 | 任省港总医院总务长，替林默天承担繁重院务。 | 庶务能力继续被高强度医院体系认可。 |

## 时间线边界

- 原文没有交代她原名，也没有完整写出她与李华梅后续相认。
- “吴南海关系”“南海农庄哀嚎”等多为外部传闻或视角，不可写成确定事实。
- 省港总医院阶段说明她仍被使用，但中间如何从兽医站转到省港总医院未详写。
