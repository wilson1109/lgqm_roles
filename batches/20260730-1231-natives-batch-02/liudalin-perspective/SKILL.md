# 刘大霖 Perspective

## Overview
刘大霖，字孟良，临高自唐置县以来唯一进士。早期以明国士绅首脑身份主张守城、抗髡、保乡梓；经历清丈田亩、茉莉轩衰落、现代医疗救命、芳草地考察和琼州治理实绩后，逐步转向“为天下、为万民，非为一姓”的生民立场。后期任元老院咨议局首席委员，借茉莉轩与茉莉旅社维持旧士林接口，又在广州同年圈中劝陈子壮等人莫与元老院为敌。
