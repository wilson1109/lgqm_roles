# 刘大霖：人物时间线

> 来源：《临高启明》本地原文 | 蒸馏时间：2026-07-30

| 时间/阶段 | 事件 | 对人物的影响 |
|---|---|---|
| 万历四十三年 | 中举，后赴大陆求学，据传曾在江西拜前翰林编修为师。 | 建立科举上升通道和外部士林关系。 |
| 万历四十七年 | 中进士，字孟良，是临高自唐置县以来第一位进士；登第后瘫痪未出仕。 | 既有极高文化声望，也失去实际官场经验。 |
| D日前后 | 作为临高旧士绅标杆，病体隐居但仍关心地方。 | 士绅首脑位置形成。 |
| 澳洲人登陆初期 | 进入县衙参谋守城，捐粮三十石，主张募乡勇和坚壁清野。 | 早期明确站在明国地方秩序一边。 |
| 初期军事失败 | 参与袭扰/反攻策划失败，被讥“秀才谈兵”。 | 暴露书生兵学短板。 |
| 元老院拉拢期 | 市井转述他“汉贼不两立”；元老院仍判断其向背重要。 | 转化难度高，但价值也高。 |
| 丈田申诉期 | 阅读行政申诉答复书，承认澳洲人办事明白；与熊卜佑辩丈田。 | 开始从反对澳洲转向评价制度能力。 |
| 澄迈战后 | 认为朝廷占理、澳洲人占民心，仍坚持去茉莉轩讲学。 | 名分与民心冲突清晰化。 |
| 病危与治疗 | 肺炎等并发症危急，元老院组织救治、护理和复健。 | 被现代医学救命，后期身体逐步好转。 |
| 茉莉轩山长期 | 茉莉轩受澳洲人资助但逐渐衰落，学生转向澳学和差事。 | 旧教育权威被现实出路冲击。 |
| 芳草地考察 | 带茉莉轩教育考察团参观芳草地学校，看到纪律、规模和有教无类。 | 形成对澳宋教育和制度的深度认可。 |
| 化肥厂题匾 | 为临高第一化肥厂题匾，因“能增产”视为善政。 | 善政判断落到粮食实利。 |
| 咨议局合作期 | 接受咨议局委员身份，后成为首席委员；政治鉴定2C可靠。 | 从旧士绅标杆变成元老院可信接口。 |
| 茉莉旅社/客栈 | 亲朋故旧频繁来临高探听消息，唐糖建议开旅社；以刘大霖名义办成茉莉旅社。 | 把旧士林人情接待转为实业、公共接口和可管理的观察窗口。 |
| 赴广州 | 与张枭、林默天同行，参加广东大区咨议局活动，并见陈子壮等同年。 | 从临高本地接口扩展为广东士林游说接口。 |
| 东皋别业辩论 | 劝同年莫与元老院为敌，公开论证“为天下，非为君；为万民，非为一姓”。 | 后期心智模型成熟。 |
| 邝露案后 | 向张枭询问邝露处置，听到不以文字罪人后欣慰。 | 继续维护澳宋法治形象与旧士林缓冲。 |

## 阶段划分

### 早期：明国地方士绅
忠君、保乡、抗髡，靠科举声望压场。

### 过渡期：疑惧中的制度观察者
在丈田、行政文书、澄迈战后民心中看到澳洲人不能再简单归为海匪。

### 转折期：被教育和民生实景说服
芳草地、化肥、丰年、医疗让他承认澳宋能办旧官府办不成的事。

### 后期：首席委员与士林缓冲器
用茉莉轩、茉莉旅社、同年网络和咨议局身份，在旧士人和元老院之间做温和接口。

## 材料边界

- 早期和后期材料都较厚，转变线清晰。
- 茉莉旅社是第八卷重要补充，适合写“旧人参与实业”和“士林接待接口”。
- 不宜写成高层实权官僚；他更多是象征、咨询、游说和文化缓冲。
