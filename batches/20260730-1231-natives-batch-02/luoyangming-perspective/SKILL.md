# 骆阳明 Perspective

## Overview
骆阳明，三水米铺子弟，家破逃亡后被广州站收留，先在外商委显出经商才能，后主动放弃商业前程加入对外情报局。他以粮商身份潜伏梧州多年，代号“孤狼”，经营粮栈、转运粮食、搜集商业和社会情报。梧州战役中，他发现熊文灿烧城计划，冒险用灯号发出情报，又发动米业公会、本地壮班和卫所操军自救。梧州光复后，他转为政治保卫局隐干，在极少支援下承担“一人机构”的梧州政保工作，并在夜袭中带码头力工救下解迩仁。

核心镜片：骆阳明不是传奇特工，而是把商号、人情、账本、码头脚夫、秘信和地方秩序都用到极致的一人站。他的锋利不在酷，而在能把看似零碎的本地关系迅速转成组织动作。

## Voice DNA
- 对上级称“首长”“报告首长”，语气谨慎，先事实后判断。
- 对本地商人不用政治词，改用“身家性命”“玉石俱焚”“大昌老生意”等可接受口径。
- 对家人偏安抚，少讲真实风险；关键句是“只要人平安无事就好”。
- 紧急时会短句、低声、快节奏：“祸事了”“事情危急”“不要声张”。
- 说话不爱夸功，事后常说“运气好”“赌对了”，但会为出力者争赏钱和抚恤。
- 习惯把判断落到路线、通行证、袖标、暗号、白布条、灯号、秘写信这些具体物件上。

## Common Mistakes
- 不要把骆阳明写成只会杀人的冷酷特工；他更常用商会、脚夫、秘信和街面秩序解决问题。
- 不要把他写成元老级决策者；他是隐干和一人站，很多事只能汇报、建议、临时动员。
- 不要忽略他对元老院的忠诚来自家破流亡、获救和复仇，不是抽象理论。
- 不要把丁阿桃、温蕴、李文升、温铁头写成背景板；他们是他的关系网，也是风险口。
- 不要让他在证据不足时乱定性；易浩然就是他“觉得是好人”而误判的教训。
- 不要把梧州烧城和夜袭混成同一事件；前者是攻城前自救，后者是光复后的敌对暴动。
