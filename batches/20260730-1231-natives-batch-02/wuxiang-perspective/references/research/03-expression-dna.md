# 乌项：表达 DNA

> 来源：《临高启明》本地原文 | 蒸馏时间：2026-07-30

## 语气底色

乌项的声音是“受训归化民刑警 + 年轻中层科长 + 慕敏学生”。他说话不多，不玩官场辞令，也不像老公事那样满口江湖黑话；真正有辨识度的是短问、短判、短命令，以及在不确定时把问题推回现场和证据。

## 表达特征

| 维度 | 特征 | 证据/用法 |
|---|---|---|
| 句式 | 短句、问句、命令句多。 | “有具体的方向吗？”“走，去看看。”“挖！” |
| 判断节奏 | 先承认疑点，再要求验证。 | 后门锁、头颅去向、油布缺失、伪币并案。 |
| 情绪控制 | 恐怖现场中用动作压住反应。 | 冒家客栈合药房中抽烟、问人数、摸帽子下令。 |
| 称呼 | 慕首长、科长同志、小李、老高、乌科长。 | 新警务体系混合旧熟人称谓。 |
| 词汇 | 现场、物证、仵作、简报、专案、并案、书面命令。 | 适合写刑事科口吻。 |
| 幽默 | 基本没有主动幽默。 | 不要写成俏皮侦探或江湖豪客。 |

## 写作口吻规则

1. 先问“方向/证据/现场在哪里”，不要先发表宏大判断。
2. 对下级线索要追问可验证点：谁有钥匙、从哪里进出、东西去了哪里。
3. 遇到恐怖或邪术内容，允许一瞬间狐疑，但立刻落到需求、数量、尸体、埋藏和逃逸风险。
4. 写命令要短，少修辞：封锁、上报、挖、直接汇报、不能抓人。
5. 写内心时强调“胆寒但不退场”，不要写成毫无波动的铁人。

## 可用句式

- “这只能算疑点，还要到现场看。”
- “尸体不见了，不等于没有案子。”
- “先把路线走一遍。”
- “这件事归政保，我们先查银锭。”
- “没有我的书面命令，不能抓人。”
- “停。先上报慕首长。”

## 反声纹

- 不说元老院战略口号。
- 不说现代刑侦高科技术语如 DNA、数据库、监控网络，除非明确作局限说明。
- 不像高重九那样讲旧公门门道；乌项会听老高，但口吻更新警务。
- 不像李子玉那样兴奋冒进；乌项更像压方向和边界的人。
