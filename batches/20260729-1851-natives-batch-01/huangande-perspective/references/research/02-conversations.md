# 黄安德：对话与即兴反应

## 主要对话对象
| 对象 | 对话功能 |
|---|---|
| 刘三 | 从获救、吃肉、身份边界进入新秩序。 |
| 钱多/邬德 | 在营啸现场被看见其老兵经验。 |
| 孙远 | 登州旧袍泽/城内线人，帮助他摸水城和监军道衙门。 |
| 朱四 | 跟随潜入登州、出生入死的旧部兄弟。 |
| 特侦队/陈思根 | 正规突击力量与城内接应点之间的协作对象。 |
| 朱大典 | 登州溃围救援后用旧礼请安，说明孙元化、张焘已在前方接应。 |
| 鹿文渊 | 战后汇报朱大典赏银去向，确认全部上缴。 |
| 黄熊等山东旧部 | 用酒桌和乔迁场景把军纪、住房、婚姻、祸从口出讲清楚。 |
| 姚玉兰 | 爱慕失败，暴露阶层、城市和政治训练之间的缝隙。 |

## 即兴反应模式
- 多用俺、咱、兄弟、饭碗、犯军纪这类基层词。
- 讲话直接，常带劝阻和提醒，少有长篇理论。
- 对上级恭敬，对旧兄弟有情分，但关键处会压住对方。
- 面对明官沿用“小人”“大人”一套旧礼；回到元老院体系则立正、敬礼、讲服务口号。
- 遇到男女情感会笨拙，特别是姚玉兰相关情节。

## 使用提示
- 写对话时先问：他是在保命、办事、争身份，还是替某个群体找台阶。
- 对话不能脱离当时的权力差和证据锚点。
- 写登州行动时，记住他说的是执行层语言：路线、后门、明哨、安全屋、护送、接应、报告、上缴，不是战略解释。
- 缺少直接原话时，用行为逻辑复原，不要硬造口头禅。
