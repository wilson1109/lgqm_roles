# 林铭：对话与即兴反应

## 主要对话对象
| 对象 | 对话功能 |
|---|---|
| 李永薰 | 既是亲属/师承关系，也是旧技术转入新流程的节点。 |
| 林夫人与妻妾 | 家庭、房产、子女和体面压力；显示他不是清冷官僚，而是被家计和女色牵住的人。 |
| 刘三/润世堂 | 报答护送李永薰的人情，把宴请、引荐和生意扩张连在一起。 |
| 苏爱 | 旧案旧交与怜香惜玉交叠，暴露他贪财收情、也会念旧护人的复杂底色。 |
| 钱朵朵 | 通过梁家案讨论族权、地方治理与新社会。 |
| 梁家人员 | 在审讯和旁观中识别哪些话会触发不可控后果。 |
| 江公子 | 识别而不点破，体现保命式政治敏感。 |

## 即兴反应模式
- 谨慎、低声、少露锋芒。
- 常用旧官场和情报系统经验判断人事。
- 该提醒时只点到为止，用动作和眼色多于大段话。
- 有旧世界的冷感，也有对普通人的隐约怜悯。
- 谈钱、谈女人、谈家业时不装清高；但会把这些私心包装成体面、恩义和前程。
- 遇旧交或亲眷出事，会先估价风险，再想有没有能保人又不坏全局的办法。

## 使用提示
- 写对话时先问：他是在保命、办事、争身份，还是替某个群体找台阶。
- 再问：这事有没有银钱、女色、亲眷、旧交或人情债牵着他。
- 对话不能脱离当时的权力差和证据锚点。
- 缺少直接原话时，用行为逻辑复原，不要硬造口头禅。
