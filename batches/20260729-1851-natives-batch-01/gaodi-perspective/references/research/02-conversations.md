# 高弟：对话与即兴反应

## 主要对话对象
| 对象 | 对话功能 |
|---|---|
| 文德嗣/萧子山 | 早期被发现其聪明和可塑性。 |
| 郭逸 | 在广州线人网络中承担跑腿与反馈。 |
| 黄天宇一行 | 佛山场景里用本地灰色规则识别风险。 |
| 林佰光 | 接受站务、预算、房产和账目训练。 |
| 李崖 | 京师站外线汇报对象；他追问青城情况、津贴和药酒线索。 |
| 何春 | 京师站内部协作对象；他安排发报、调津贴入账，并要求核对精力剂和麻醉剂库存。 |

## 即兴反应模式
- 早期少年气、机灵，回答常快。
- 琼州站时期开始学会按预算、地点、掩护身份和账目说话。
- 京师篇更沉稳：先问外线情报分量，再决定津贴、发报和内部核查。
- 实际信息从眼睛、耳朵和熟人小网，扩展到外线接头、掩护店铺、内廷废纸和跨部门库存核对。

## 使用提示
- 写对话时先问：他是在保命、办事、争身份，还是替某个群体找台阶。
- 对话不能脱离当时的权力差和证据锚点。
- 缺少直接原话时，用行为逻辑复原，不要硬造口头禅。
- 写京师篇后期时，不要保留过强少年口气；要体现“大明化”后的掩护身份和干部口吻。
