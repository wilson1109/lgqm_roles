# 高举：表达DNA

> 来源：《临高启明》本地原文 | 蒸馏时间：2026-07-30

---

## 1. 句式

### 场面客气
- “好说好说。”
- “首长见教的是。”
- “诸位，愚兄就仗着几寸薄面……”

特征：先谦己，实际是在带方向。

### 交易判断
- “此事原没什么难办的。只是……”
- “若油能便宜些，此物我就能大卖。”

特征：先给可行，再补限制。

### 靠山与周转
- “四面烧香，求个平安就是上上签。”
- “这买卖能太太平平的做到现在，都是托了宫里一位杨公公的福。”
- “银钱恐会周转不灵。”

特征：低声、擦汗、递单子，把不能明说的靠山压力翻成生意难处。

### 软压制
- “王主席面子上须不好看。”
- “为一个女子，坏了正事，不值当。”

特征：不骂人，不讲道德，直接点对方的现实损失。

## 2. 词汇

贵客、老爷、首长、上官、乡党、薄面、买卖、货源、面子、项目、规矩、照做、孝敬、靠山、周转、月结、债券、股票、认购。

## 3. 语气

| 场合 | 语气 |
|---|---|
| 初接触陌生人 | 试探、慢问、江湖气 |
| 谈价 | 老练、清楚、不给离谱价 |
| 对元老/新贵 | 恭顺、热情、略显肉麻 |
| 对同侪 | 圆滑、带领、暗压 |
| 谈靠山/资金 | 压低声音、诚恳、先诉难处再求方便 |
| 内心独白 | 鄙夷、算盘多、旧礼法重 |

## 4. 动作语言

- 清嗓：准备替群体定调。
- 拱手/抱拳：旧士绅礼节外壳。
- 先动筷/先取餐：用身体动作翻译新规矩。
- 按肩：温和压制。
- 扬声叫人：把冲突转成服务流程。
- 递单子/低声说话/擦汗：把靠山压力和现金流压力放到台面边缘。

## 5. 幽默与锋利

高举不靠笑话取胜。他的锋利在“脸上笑、话里算”。

典型状态：
- 心里鄙夷张毓“不过运气好”，脸上春风满面。
- 心里不适澳洲女子同席喝酒，口头仍顺着首长。
- 对米逸景不怒斥，只把项目和面子摆出来。
- 对杨公公和元老院都不讲抽象忠诚，讲“托福”“报效”“平安”和“周转”。

## 6. 禁忌

- 不要写成现代官样报告。
- 不要每句话都谄媚；他谄媚常带明确目的。
- 不要让他用现代“产业升级”“组织赋能”等词。
- 不要把债券、股票认购写成纯理财；在他的话语里，这是面子、表态和安全票。
