# 高举：人物时间线

> 来源：《临高启明》本地原文 | 蒸馏时间：2026-07-30

---

| 时间 | 事件 | 对人物的影响 |
|---|---|---|
| 天启七年前 | 在广州濠畔街经营番货、通洋贩私，部分产业与宫里杨公公相关。 | 形成风险意识、门路意识和番货行情能力。 |
| 天启七年二月 | 澳洲人第一次从高宅后院出现，高举由恐惧转为会面。 | 成为穿越集团最早的土著接触窗口。 |
| 初次交易 | 评估粉盒、玻璃杯、密胺、塑料等货物，按广州行情开价。 | 建立“货色胜过神话”的判断模式。 |
| 第二次交易 | 清点澳货、惊叹煤油灯，支付白银黄金瓷器。 | 形成可持续贸易关系。 |
| 第二次交易后 | 封口知情人员，防同行摸清货源。 | 货源独占意识成型。 |
| 秘宅阶段 | 因海外商人不能买房且奇货惹眼，提供高家城内下处。 | 广州大陆门户进一步稳定。 |
| 杨公公南下 | 高举向杨公公线输送澳洲奇货，又面临生祠摊派和现金流压力。 | 旧靠山既保护他，也会反过来吞噬利润。 |
| 绑架风波后 | 高举原想等澳洲人求助再卖人情，见对方自行解决后马上补帮忙、谈赊账。 | 认识到澳洲人实力超出普通海商，关系维护优先级上升。 |
| 穿越前最后交易 | 接受价值二十万两的赊货，成为后续广州照应节点。 | 从现款贸易转为信用绑定。 |
| 澳宋入穗后 | 高家成为早期合作者之一，高举进入新秩序。 | 从私商代理转为地方协商人物。 |
| 第七卷集体婚礼 | 与张毓周旋，观察何家旧瓷器和澳宋权力，带头自助取餐。 | 既恐惧新政权清算能力，又学会做仪式翻译者。 |
| 第七卷项目推广期 | 试探张家机器工厂、贷款和订单，考虑投资澳洲式绸缎机房。 | 从海贸暴利思维转向工业稳定收益思维，但仍谨慎。 |
| 第七卷新文艺场景 | 对澳洲女子同席和歌舞不解，接受“不明白只管照做”。 | 新秩序适应术明确化。 |
| 第七卷南洋认购 | 通过口信协调张毓债券/股票额度，洪璜楠也把高举当作广州财力标尺。 | 金融认购变成身份排序和忠诚表态。 |
| 第八卷深耕经营(上) | 元老侧提及高举与宫里关系；广州外部人物也以高家铺子辨认澳洲货源。 | 旧门路仍被澳宋纳入情报与政治想象。 |
| 第八卷临穗交流会 | 以广州工商联合会主席、市政府顾问身份赴临高；王主席夸其币制改革立场坚决、积极要求进步。 | 其“从龙最早士绅”身份被公开确认。 |
| 第八卷宴会 | 士绅谦让过度时，带头表忠和动筷。 | 成为广州士绅群体的场面定调者。 |
| 第八卷米逸景事件 | 以王主席面子和米家项目软压闹事者，恢复宴会。 | 软刀子权术成熟。 |

## 阶段划分

### 早期：番货商人与灰色门路

核心能力是识货、谈价、保密和利用门路。

### 接触期：澳洲货源代理

从恐惧澳洲人的异常，到把他们转化为可持续货源。

### 绑定期：旧靠山与新货源同算

一边向杨公公报效求平安，一边向澳洲人争取信用和赊账。

### 入穗后：新秩序协商者

既巴结元老和样板户，又帮助旧士绅理解新规矩。

### 成熟期：工商联场面人

能在宴会、项目、冲突中替广州群体定调，用软话办硬事。

## 材料边界

- 高举材料主要集中在第一卷、第七卷、第八卷，厚度中等。
- 有足够证据写商绅周旋、货源控制、场面治理和工业投资试探。
- 第一卷材料足以支撑“门路共生/现金流周转”，不要只取最初见面交易。
- 不足以写成有完整政治理论或独立行政能力的高层干部。
