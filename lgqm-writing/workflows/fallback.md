# Workflow: 回退与澄清

## Trigger
路由器匹配失败或用户输入太模糊时加载本文件。

## Protocol

### 场景 A: 无匹配（用户输入没有命中任何角色/领域）

1. 从 `references/character-catalog.md` 提取分类摘要
2. 按分类（元老/规划民/明朝历史人物）和领域（军事/政治/商业/医疗/教育...）列出可用角色概况
3. 引导用户缩小范围：
   > 你的请求没有匹配到具体角色。你可以：
   > - 指名角色："用[角色]视角"
   > - 描述场景："写[地点/事件]的场景"
   > - 指定领域："[军事/政治/商业/医疗...]相关"
4. 若用户输入的确实是临高世界之外的话题，礼貌说明本 skill 只服务临高启明同人写作

### 场景 B: 匹配过多（>5 个角色命中）

1. 按优先级排序：scenario-mapping 推荐 > domain-index 领域匹配 > 纯关键词
2. 展示 top-5，各带一行领域说明
3. 询问用户："需要更精确的筛选吗？可以补充地点/时间/事件类型。"

### 场景 C: 用户输入模糊（无法分类）

澄清问题（一次问一个）：
1. "你想写**场景**（描述一段剧情），还是用**某个角色**的视角？"
2. "发生在哪个地点/时间线？（临高 / 广州 / 雷州 / 山东 / 江南 / 明朝朝廷）"
3. "冲突类型？（政治 / 军事 / 商业 / 技术 / 人际关系）"

### 场景 D: Skill 调用失败

1. 检查角色 skill 是否已安装（`*.claude/skills/<skill>/SKILL.md` 是否存在）
2. 返回已成功部分 + 标注："以下角色未能加载：[name]。请确认已安装对应 *-perspective/ 目录。"
3. 提示安装方式：运行 `python lgqm-writing/scripts/install.py`

## Output Format

清晰列出可用选项，一次只问一个澄清问题，避免连续追问。
