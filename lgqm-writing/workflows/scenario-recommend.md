# Workflow: 场景驱动角色推荐

## Trigger
路由器分类为 **SCENARIO_WRITING** 时加载本文件。

## Protocol

1. **提取场景关键词**：从用户输入提取地点、事件、冲突类型、主题
   - 例："雷州糖厂的冲突戏" → 雷州 + 糖业 + 冲突
   - 例："元老院会议上争论工业化路线" → 元老院 + 工业化 + 政治
2. **匹配领域**：在 `references/domain-index.md` 中找关键词对应的领域
3. **查场景映射**：在 `references/scenario-mapping.md` 中找匹配的场景条目
   - 读取该场景的"领域标签"和"推荐视角组合"
4. **解析到具体角色**：把领域标签通过 `domain-index.md` 解析为角色列表
   - 按"主视角 > 次级 > 对立面"分层
5. **输出 top-3 推荐**：
   - 每个推荐给出：角色名 + skill 名 + 擅长领域 + 为什么适合本场景
   - 询问用户是否确认，或调整推荐

## Output Format

```
推荐视角（按适合度排序）：
1. [角色A]（[skill名]）— [领域] — 理由
2. [角色B]（[skill名]）— [领域] — 理由
3. [角色C]（[skill名]）— [领域] — 理由

主视角建议：[A]，暗线建议：[C]
请确认使用哪个视角，或我可以用 [A]+[B] 双视角处理。
```

## 边界
- 不确定时优先推荐，不擅自替用户决定视角
- 若用户确认，转 `multi-character.md` 或 `single-character.md` 执行
