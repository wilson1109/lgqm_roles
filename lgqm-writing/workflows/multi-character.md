# Workflow: 多角色编排

## Trigger
路由器分类为 **MULTI_CHARACTER** 时加载本文件。

## Protocol

1. **解析角色组合**：提取所有点名的角色
2. **查关系**：从 `character-catalog.md` 中查各角色的领域，推断关系类型
   - 已知关系对：明朗-慕敏（夫妻）、李梅-明朗（母子）、文同-常师德（同事）等
   - 冲突对：杜雯-萧子山（理想主义 vs 现实政治）、张枭-计委（对抗）等
3. **确定主次**：
   - 主视角：1 个（叙事主体）
   - 次级视角：1-2 个（衬托、回应）
   - 视用户请求灵活调整
4. **串行调用**：先主视角后次级（避免上下文过载）
   ```
   Skill(skill="主视角skill", args="从主视角回应这个场景")
   Skill(skill="次级视角skill", args="从次级视角回应同一场景")
   ```
5. **合成**：
   - 交替叙述，标注角色名
   - 保持各自 voice（来自各自 skill 的表达 DNA）
   - 若角色间有已知冲突，明确呈现张力

## Output Format

```markdown
**【角色A】**（A 的视角/对白，带 A 的语气特征）
【叙述】场景推进
**【角色B】**（B 的视角/对白，带 B 的语气特征）
【叙述】B 对 A 的反应
...
```

## 边界
- 不强制所有角色出场；对场景无贡献的角色跳过
- 角色意见冲突时，不强行调和，呈现分歧
- 多角色调用失败时，降级为已成功的角色视角 + 标注缺失
