# 场景-角色映射 (Scenario-Character Mapping)

> 本文件按**领域标签**组织（而非硬编码角色名），路由器在运行时通过 `domain-index.md` 动态解析到具体角色。新增角色只要被 `build_catalog.py` 正确打上领域标签，即可自动进入场景推荐。

## 场景类型索引

### 元老院政治（内斗 / 派系博弈 / 人事）
- 领域标签: 政治/人事, 广州治理, 商业
- 推荐视角组合: 主视角=政治/人事, 次级=商业, 对立面=士绅
- 写作提示: 焦点在程序手段、人事安排、话语权争夺；避免写成简单好坏对立。

### 雷州糖业线（经济战争 / 基层政权）
- 领域标签: 雷州, 工业, 情报, 特种作战
- 推荐视角组合: 主视角=雷州+工业, 暗线=情报+特种作战
- 写作提示: 焦点在技术落地、基层组织、情报与商业的边界。

### 广州治理（城市管理 / 旧势力博弈）
- 领域标签: 广州治理, 警务, 商业, 士绅, 教育
- 推荐视角组合: 主视角=广州治理, 次级=警务+商业, 对立面=士绅
- 写作提示: 城市治理是本书最丰富的舞台，新旧碰撞最有戏剧性。

### 大明朝廷（末世视角 / 天书政治）
- 领域标签: 大明朝廷, 士绅, 军事, 满清
- 推荐视角组合: 主视角=大明朝廷, 军务线=军事, 暗线=满清+士绅
- 写作提示: 明廷视角最考验历史功底，要写出"末世勤奋的徒劳感"。

### 情报暗战（信息差张力）
- 领域标签: 情报, 政保, 海盗/海上, 商业
- 推荐视角组合: 主视角=情报, 执行层=政保, 对立面=海盗/海上
- 写作提示: 情报线要写出"信息差"的张力，而非单纯冒险。

### 军事/战争（登陆 / 治安战 / 特侦行动）
- 领域标签: 军事, 特种作战, 海军, 火工/装备
- 推荐视角组合: 主视角=军事, 战术层=特种作战, 海上=海军
- 写作提示: 战争要写出后勤、伤亡、纪律和命令链的代价。

### 女性权利（妇联 / 女权 / 女性政治）
- 领域标签: 女性权利, 政治/人事, 宣传/传媒
- 推荐视角组合: 主视角=女性权利, 次级=宣传/传媒, 对立面=士绅
- 写作提示: 杜雯式的革命话语 vs 程咏昕式的现实策略之间的张力最精彩。

### 医疗/防疫（鼠疫 / 医院 / 公共卫生）
- 领域标签: 医疗, 防疫, 化工, 教育
- 推荐视角组合: 主视角=医疗+防疫, 次级=化工, 基层=教育
- 写作提示: 防疫是制度与人性碰撞的绝佳场景，写接触史和隔离上报的细节。

### 工业/化工（技改 / 火工 / 制造）
- 领域标签: 工业, 化工, 火工/装备, 军事
- 推荐视角组合: 主视角=工业+化工, 试验=火工/装备, 应用=军事
- 写作提示: 工业化不是线性的，"能做"不等于"能量产、能运输、能实战"。

### 山东/难民（据点 / 收容 / 发动机行动）
- 领域标签: 山东, 难民/收容, 军事, 教育
- 推荐视角组合: 主视角=山东+难民/收容, 军队=军事, 改造=教育
- 写作提示: 难民收容是工程、补给和地方秩序的组合，不是纯军事冒险。

### 江南/商业（丝业 / 招商 / 士商）
- 领域标签: 江南, 商业, 士绅, 情报
- 推荐视角组合: 主视角=江南+商业, 渠道=士绅, 暗线=情报
- 写作提示: 江南线要写出资本、声望、士绅关系、产业链与风险隔离的张力。

### 士绅/旧官僚（转向 / 名教 / 旧秩序）
- 领域标签: 士绅, 大明朝廷, 教育, 农业
- 推荐视角组合: 主视角=士绅, 朝廷=大明朝廷, 基层=农业+教育
- 写作提示: 士绅转向是新旧秩序碰撞的核心，写"知髡以制髡"的纠结。

### 商业/金融（贸易 / 钱庄 / 粮食）
- 领域标签: 商业, 雷州, 情报, 工业
- 推荐视角组合: 主视角=商业, 资本=雷州, 暗线=情报
- 写作提示: 商业线要写出账本、信用、渠道和风险，而非简单赚钱。

### 宗教/教会（渗透 / 移风易俗）
- 领域标签: 宗教, 宣传/传媒, 教育, 大明朝廷
- 推荐视角组合: 主视角=宗教, 思想=宣传/传媒, 民间=教育
- 写作提示: 宗教是组织资产、思想入口与礼仪平台的组合。

### 元老日常（生活化 / 人际关系）
- 领域标签: 政治/人事, 广州治理, 农业
- 推荐视角组合: 按具体场景选择，夫妻/母子/同窗组合
- 写作提示: 生活化场景最能体现穿越者的身份错位感。

### 满清/辽东（外压 / 后金）
- 领域标签: 满清, 军事, 大明朝廷, 海军
- 推荐视角组合: 主视角=满清, 对线=大明朝廷, 侧翼=海军
- 写作提示: 满清线的核心是"国困民穷中的帝国创业者"的判断。

### 流寇/民变（内乱 / 农民战争）
- 领域标签: 流寇/民变, 军事, 难民/收容, 大明朝廷
- 推荐视角组合: 主视角=流寇/民变, 镇压=军事, 余波=难民/收容
- 写作提示: 流寇要写出动员逻辑，而非简单暴民。

## 交叉校验说明

`build_catalog.py` 运行时会对比本文件引用的领域标签和 `domain-index.md` 中实际存在的标签，输出缺失/未覆盖警告。新增场景或新增角色后建议重跑 `build_catalog.py` 检查。
