# 张枭 - 人物时间线

| 时间节点 | 事件 | 心理/认知变化 |
|---------|------|-------------|
| 旧时空·大学 | 主修制药工程，大四未毕业 | 正常人生轨迹 |
| 旧时空·两年前 | 大地震中失去全部亲人 | 深度抑郁，想过自杀，后想通"自己是父母留在世上的唯一血脉" |
| 旧时空·BBS | 看到虫洞招募贴 | 命运的齿轮开始转动 |
| D日 | 落水被毕生所救 | 与毕生成为好友 |
| D日后早期 | 被当作"基本劳动力"使用 | 无存在感，做路人甲 |
| 1629年初 | 毕生因麻醉剂过量死亡 | 愤怒→觉醒："没有功劳在组织里是混不下去的" |
| 1629年春节后 | 调任制药厂技术员 | 找到方向，开始发挥专业能力 |
| 1629年中期 | 开发退热冰、乌洛托品 | 建立技术信誉 |
| 1629年后期 | 提出建立毕生基金会 | 执委会原则同意 |
| 1630年 | 私下收割黄花蒿、启动青蒿素研究 | 学会绕开体制做事 |
| 1630年 | 三亚疟疾危机，青蒿素栓剂紧急生产 | 获主席嘉奖令，声望大升 |
| 1630年4月 | 毕生基金会低调成立 | "为死者留名，为生者谋生" |
| 1630年后 | 制药二厂建设 | 磺胺、链霉素等产品线扩展 |
| 1635年(约) | 冯默风烧伤事件 | 不惜一切代价保归化民干部 |
| 1636年初 | 感染疟疾住院 | 梦境揭示旧时空未了情（莉莉） |
| 1636年 | 参与工具人革命 | 策略性克制，建议封锁医院 |
| 1636年末 | 团拜会，与郑明姜共舞唱《消愁》 | "一肚子的不合时宜都吐掉了" |

## 关键人际关系时间线
- **毕生**：D日→1629年初（死亡），贯穿始终的精神锚点
- **曾坤**：1629年药厂→长期，最亲密的专业搭档
- **郑明姜**：1629年药厂→1636年暧昧，从同事到知己
- **王企益**：1630年→长期，政治导师
- **林默天**：1629年→长期，医疗口盟友
