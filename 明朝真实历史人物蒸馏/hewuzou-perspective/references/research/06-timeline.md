## 小说中出现的时刻（第8卷·第一百六十八—一百六十九节）

| 场景 | 何吾驺做了什么 |
|------|---------------|
| 见面 | 与刘大霖寒暄，扶持行动不便的同年 |
| 第一次圆场 | 刘大霖欲警告众人→何吾驺"不妨直言" |
| 第二次圆场 | 引欧阳修"放他出一头地"回应刘大霖的"青年论" |
| 军户隐痛 | 刘大霖说李孙辰→何神情微变、擦汗——他也是军户 |
| 对髡批判 | "商鞅旧法，二世而亡""为政猛苛，绝非长治久安之道" |
| 对军制理解 | 为刘大霖解释伏波军军制——精准理解"上告"与"军令"的分离 |
| 第三次圆场 | 转移话题到澳洲兵制 |
| 京师预警 | 透露已知"琼饷"计划 |
| 面色惨白 | 明夷卦辞后唯一一次失态 |
| 散场圆场 | 替陈子壮向刘大霖解释 |

## 命运的回响（1636年后，何吾驺不知道）

| 时间 | 事件 |
|------|------|
| 1645年 | 弘光朝覆灭。南京失陷 |
| 1646年5月 | 隆武帝召何吾驺为首辅。何入直，加少傅太子太保，赐银章"辅佐中兴" |
| 1646年 | 与郑芝龙议事辄相牴牾，建言多不被采纳 |
| 1646年8月 | 福州失陷，隆武帝遇难。何吾驺仓皇逃归广东 |
| 1646年11月 | 与苏观生、顾元镜、王应华等在广州拥立绍武帝 |
| 1646年12月15日 | 清军李成栋部攻陷广州。绍武帝殉国。苏观生自缢。**何吾驺降清** |
| 1647年 | 被清廷逼令率降臣观陈子壮磔刑 |
| 1651年 | 称疾还乡，卒于家 |

> **注意**：1636年的何吾驺不知道1646年他会投降清朝，会被逼观看同年陈子壮被凌迟处死。他不知道他那"让所有人都觉得自己可能站在他这边"的策略最终会在极端情境下导向何种选择。但这条命运的弧线——从直臣到贰臣——是所有同人创作中不可忽视的潜在张力。
