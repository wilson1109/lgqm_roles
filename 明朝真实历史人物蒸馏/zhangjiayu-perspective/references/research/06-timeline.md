## 完整时间线（历史·1615-1647）

| 年份 | 年龄 | 事件 |
|------|------|------|
| 万历四十三年乙卯(1615) | 1岁 | 十二月十三日生，广东东莞万家租。字玄子，号芷园。张九龄弟九皋之后，曾祖讳宗尹，祖讳明教，父讳兆龙。祖母陈氏，母黎氏，妹石宝，妻彭氏 |
| 万历四十八年庚申(1620) | 6岁 | 少志高远，任侠使气，穿穴经史，师从林洊。酷爱诸葛武侯，登黄期峰"不绝顶不休" |
| 天启七年丁卯(1627) | 13岁 | 八月熹宗崩，九月崇祯即位 |
| 崇祯六年癸酉(1633) | 19岁 | 补广州儒学生员 |
| 崇祯九年丙子(1636) | 22岁 | 成举人（历史事件。小说中：髡贼据两广，功名冻结在秀才，未成举人） |
| 崇祯十六年癸未(1643) | 29岁 | 成进士，殿试三甲，授翰林院庶吉士。倪元璐极其赏识其诗 |
| 崇祯十七年甲申(1644) | 30岁 | 三月京师陷崇祯崩。被大顺军所获，上书李自成"请宾礼之而不臣"，长揖不跪，五凤楼被缚七日不食。间道南归。五月福王即位。阮大铖构陷，有力辩者得复职 |
| 隆武元年乙酉(1645) | 31岁 | 南都失守。与黄道周、苏观生等拥立唐王于福州。授翰林院侍讲兼编修，旋兼兵科给事中，又兼理吏、户、礼三科事。监郑彩军。十月许湾大破金声桓，解抚州之围 |
| 隆武二年丙戌(1646) | 32岁 | 正月新城之战——郑彩弃城，自带乡兵二百人力战，中箭折臂。三月募兵潮惠建"武兴营"（隆武赐名）。八月隆武帝崩（正史）/或潜遁（朱纪敦假说）。九月归东莞。十二月清破广州，拒降佟养甲 |
| 永历元年丁亥(1647) | 33岁 | 三月入东莞起兵。家人殉难（祖母陈氏、母黎氏、妹石宝赴水死，妻彭氏被执不屈断肢死）。走西乡→走铁冈→克博罗→复连平长宁→攻惠州→还屯博罗。十月十日增城大战十日，矢尽炮裂将伤卒死，自投野塘死。年三十三 |

## 小说时间线（《南海的涟漪》·当前）

| 章节 | 事件 | 角色状态 |
|------|------|---------|
| 第08-09章 | 元老院情报分析：识别张家玉为可转化对象 | 尚未出场，已被标记 |
| 第17章 | 母病求药，被林洊引入严庵 | 至孝驱动，被动入局 |
| 第18-19章 | 严庵反髡集会，被推为卧底。结拜张穆。 | 被赞誉冲昏→半推半就接受任务 |

| 第27-28章 | 见习参议上任。读《中国历代政治得失》。林洊打探情报→警觉。初见赵和宁。街头遇张穆。 | 两难成型：师友vs恩人 |
| 第30-32章 | 随张枭巡查桑园围/九江大墟。与赵和宁互动加深。听口琴。 | 学新东西+恋爱萌芽 |

| 第43章 | 献策"让和宁管黄氏案" | 策略价值被认可 |
| 第46-48章 | 写诉状。献策搜朱氏。随军搜查。劝阻升级冲突。 | 主动帮元老院打击反髡势力 |
| 终章后（未写） | 林洊/张穆的摊牌尚未到来 | 定时炸弹未引爆 |
