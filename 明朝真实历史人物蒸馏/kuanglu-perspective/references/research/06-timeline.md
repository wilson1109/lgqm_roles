## 完整时间线（历史·1604-1650）

| 年份 | 年龄 | 事件 |
|------|------|------|
| 万历三十二年(1604) | 0 | 二月初六生于南海大镇乡。生而甘露降庭。憨山德清赐名"瑞露"、摩顶"天上玉麒麟"、赠偈"要留正气动南天" |
| 1608 | 5 | 早孤，作《甘露诗》应声而就 |
| 1613 | 10 | 赴鼎湖山随憨山大师累年，遍读儒释道经籍 |
| 1616 | 13 | 入泮（诸生）。慕坟典左氏庄骚古文，不沾沾举子业。覃思忘寝食，抵触树木倾坠坑堑而不觉 |
| 约1617-20 | 14-17 | 五体书答卷被黜→大笑而去。任诞纵酒散发徜徉市中，为礼法之士所仇 |
| 1623 | 20 | 与从兄邝湛之读书罗浮明福洞。兼习武艺，剑刀骑射皆精。湛之后从袁崇焕战死边塞 |
| 1628 | 25 | 袁崇焕起复督辽。陈子壮于光孝寺设饯行会，邝露题七律四首 |
| **1634（小说前一年）** | **31** | **上元夜骑马闯县令黄熙孕→被削功名→弃家入广西瑶区** |
| 1634-36 | 31-33 | 为瑶女帅云嚲娘掌书记，著《赤雅》三卷。北游：湘鄂→皖（访阮大铖）→苏→金陵→京师 |
| **1636（小说现在）** | **32** | **返乡。髡贼据两广。陈子壮宅反髡密会。殴打黄熙胤→被拘留→张枭释放。** |
| 1636 | 33 | 出甬东泛海登普陀落伽山，作《海览》篇 |
| 1645 | 42 | 移书削籍与阮大铖绝交。隆武立，起为中书舍人。与梁稷合疏为袁崇焕白冤 |
| 1646 | 43 | 绍武朝中书舍人。十二月清军陷广州，长子邝鸿率北山义旅千余战死 |
| 1650 | 47 | 奉命还广州筹兵备。守城逾十月。十二月初一城破，抱琴殉节。次子邝闲同战死。父子三节 |

## 小说时间线（《南海的涟漪》·当前）

| 章节 | 事件 | 角色状态 |
|------|------|---------|
| 第01-04章 | 梅关返乡→疍民船→看髡贼治理 | 离乡三年初归，边走边观察边骂 |
| 第05-07章 | 陈子壮宅反髡密会 | 信息最少（刚回来），但观察最敏锐（髡贼治国理政的细节） |
| 第20-21章 | 尊经阁写反诗→打黄熙胤→被拘留 | 冲动爆发——性格驱动的行动，非战略计算 |
| 第23章 | 陈子壮在东皋别业求刘大霖说情 | 不在场——但整个聚会为他而设 |
| 第27-28章 | 黄熙胤告状→张枭释放→狱中吹牛→张穆接人 | 狂到底——监狱也成了他的舞台 |

## 性格发展轨迹

| 阶段 | 年龄 | 核心特征 |
|------|------|---------|
| 神童 | 5-16 | 憨山赐名、"天上玉麒麟"、五体书答卷、大笑而去——**狂已成形** |
| 青年 | 17-30 | 散发行歌市中、骑马闯县令、亡命广西——**狂到付出代价但仍不回头** |
| 壮年（小说现在） | 31-32 | **性格完全定型**。返乡→反髡议事→打人写反诗→监狱吹牛——狂是日常 |
| 中年 | 33-46 | 著《赤雅》成书、《峤雅集》刊刻、阮大铖绝交、为袁白冤——**狂中见正** |
| 殉国 | 47 | 守城十月→拒逃→抱琴殉节——**狂的终点是忠烈** |
