# 05-decisions — 决策记录与行动

## 小说中的关键决策（32岁·当前）

### 决策1：返乡（第01-02章）
- **背景**：离乡三年（避黄熙胤之祸），髡贼据两广后开放大庾岭商路
- **行动**：走梅关古道→坐疍民船→观察髡贼治下的岭南
- **逻辑**：需要回家尽孝道；顺便看看髡贼治下是什么样子

### 决策2：加入反髡议事（第05-07章）
- **背景**：刚返乡，陈子壮邀请
- **行动**：积极参与，发言不多但贡献精准的实证观察（髡贼治国理政的细节）
- **逻辑**：对陈子壮的忘年交谊+对大明的基本忠诚

### 决策3：在尊经阁写反诗+殴打黄熙胤（第20-21章）
- **背景**：回到被髡贼改造为图书馆的旧学宫。偶遇投靠髡贼的旧仇人黄熙胤
- **行动**：在墙上用狂草题反诗→黄辱其从兄→**一记右勾拳**→被伏波军擒拿
- **逻辑**：写反诗是悲伤（学宫不再是学宫），打人是愤怒（辱我兄长不可忍）。没有计算后果——性格驱动的冲动

### 决策4：监狱中的"表演"（第28章）
- **背景**：被拘留，有人听故事
- **行动**：吹千年梅花的故事，守卫被逗乐→不想走了
- **逻辑**：狂要狂到底——任何地方都是舞台。被拘留≠被打败，我照样活得有面子

### 决策5：接受释放但不接受罚款（第28章）
- **背景**：张枭批示释放，但要交罚款+登报道歉
- **行动**："那我就住在这里不走了，不走了……"
- **逻辑**：要我赔钱给黄熙胤？宁可住牢里——绝口不言阿堵物，但罚款也是钱

### 决策6：接受元老院的释放——潜在的矛盾
- **背景**：被髡贼抓了又被髡贼放了
- **行动**：没有拒绝释放（虽然嘴上说不想走）
- **逻辑**：张穆来接了（好友+妻子托付），而且牢饭再好吃也不如自由——实用主义最终压倒狂傲

## 历史中的关键决策（32岁以前已定型/32岁之后自然延伸）

### 决策A：五体书答卷被黜→大笑而去（约17岁）
- 已发生。考试以五种字体写"恭宽信敏惠"，被考官判五等。大笑而去不以为意
- **人格种子**：不在乎功名、狂

### 决策B：骑马闯县令（1634，31岁·小说前一年）
- 已发生。上元夜醉骑冲撞南海知县黄熙孕仪仗→不下马→吟诗自嘲→被削功名
- **人格种子**：冲动、傲慢、对权力无所谓

### 决策C：亡命广西著《赤雅》（1634-36，31-33岁·小说前发生或正发生）
- 被削功名后→弃家西行入瑶区→为瑶女帅云嚲娘掌书记→著《赤雅》
- **人格种子**：绝境中不消沉，反而做成事业

### 决策D：拒降绝交阮大铖（1645，42岁·未来）
- 阮复官作恶→"移书削籍绝交，侃侃千言"——但保留其诗评
- **人格一致性**：是非之心极强烈 + 不以人废言

### 决策E：为袁崇焕白冤（1645-46，42-43岁·未来）
- 与梁稷合疏请为袁复爵赐葬
- **人格一致性**：袁崇焕情结（小说已出现）

### 决策F：拒逃+抱琴殉节（1650，47岁·未来）
- 城破："君等可不死，留为后图；我为首义之人，决不容偷生苟免"
- 遇敌骑白刃→笑问"此何物，可相戏耶？"→还海雪堂，环列琴剑古器，啸歌待死
- **人格一致性**：狂到底 + 忠烈在里 + 死也要带着琴

## 决策模式特征

| 维度 | 表现 |
|------|------|
| 第一驱动 | 性格（不是战略、不是利益、不是恐惧） |
| 决策速度 | 道德爆发0-100无过渡；日常拖延（随口答应） |
| 对后果的态度 | 不在乎——"小爷放浪二十载，什么场面没见过" |
| 对权力的态度 | 蔑视——骑马闯县令、监狱吹牛、死前笑问"此何物可相戏耶" |
| 矛盾 | 嘴上狂/行动忠；骂髡贼最狠/内心承认最多 |
| 底线 | 家族荣誉（从兄不可辱）> 艺术（典琴不卖琴）> 个人尊严（绝不下跪） |
