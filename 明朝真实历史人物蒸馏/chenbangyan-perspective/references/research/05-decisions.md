# 05 - 决策记录与行动

## 关键决策时间线

### 决策1：结束讲学，北上献书（1644年，41岁）

**背景**：甲申国变，崇祯自缢。邦彦在锦岩教书为生，家境"单微""笔耕岁自给"。

**决策**："乃辍讲业，谢罢生徒，闭户草《中兴政要书》数万言，走南都上之。"

**逻辑**：
- 触发："不报国，非丈夫也"
- 行动：放弃稳定教职 → 闭门著书 → 千里跋涉献书
- 代价：失去收入来源、离开家庭
- 风险：一个无官职的书生上书，很可能石沉大海

**结果**："书上不报"——福王置之不理。归装"一蒯缑"（只剩一把用草绳缠结的剑）。

**反思**：邦彦没有公开抱怨。但《疏草成》诗中"空言何补圣明朝"已透露出失落。

### 决策2：监粤兵援赣，数谏苏观生（1646年，43岁）

**背景**：隆武朝任兵部职方司主事，监狼粤兵万人出南安。苏观生以枢辅督诸军援赣。

**决策**：屡次向苏观生陈述作战方略 → 被拒 → 继续进言（未放弃）

**事后验证**：唐王败后，清军进军路线"悉如邦彦所说"。

### 决策3：谏苏观生东进（1646年秋，南安）——最关键的决策预判

**决策内容**：力劝苏观生率重兵东走惠潮，扼控漳泉未溃之地，自请留守南安。

**论证结构**：国乱先内，国危先外 → 独两粤存 → 扫境内以属阁下，危而弃之，奈天下何 → 东扼惠潮 → 两粤存亡，系于东向，迟则亡，速则存 → 南安守事，愿以委邦彦

**结果**：观生不听，旋师入粤。随后清军"自福建攻陷潮州、惠州，即用潮惠印符，日为文书寄广州报平安，而以轻兵来袭"——完全按照邦彦预测的路线。

**反思**：这是邦彦一生最精准的战略预判，但也是最无力的一次——他什么都说对了，什么都改变不了。

### 决策4：奉表劝进桂王 + 得知绍武分裂后的应对（1646年冬）

**背景**：苏观生派邦彦至梧州迎桂王东返，行后观生在广州另立绍武帝。邦彦至梧州方知。

**决策链**：
1. 梧州上启 → 桂王深夜龙舟召见 → 建议"速返端州，正大位以属人心" → 被授兵科给事中
2. 东还广州宣谕观生 → 不入城，使从人奉敕 → 遗书苏观生指陈利害 → 观生不听且以兵掩袭肇庆
3. 西归朝廷不得 → "易姓名林居士，入高明山中"

**分析**：这是一个渐进失望的决策链：
- 第一步：仍在体制内努力（劝桂王正大位）
- 第二步：完成使命但不妥协（不入广州城）
- 第三步：发现双方都不可为，选择隐退而非投靠任何一方

### 决策5：山中出→起义兵（1647年正月，44岁）——最关键的人生命运转折

**背景**：清军破肇庆，围桂林。邦彦隐居高明山中。

**决策**：走出山林 → 独驾扁舟入甘竹滩 → 说服大盗余龙 → 以奇兵袭广州（围魏救赵）

**逻辑**：
- 观察："临西江口，望见敌人旌旗"
- 判断："若乘其未定，得奇兵径袭广州，此孙膑所以解赵也"
- 行动：一个人、一条船、说服几万盗贼攻广州
- 目标：围魏救赵——不是真的要打下广州，而是迫使围桂林的清军回援

**结果**：成功！余龙攻广州四日，佟养甲飞骑追成栋军还，"桂林由是得全"。

### 决策6：拒降（1647年）——道德绝对主义的极限测试

**背景**：佟养甲执其妾及二子（和尹、虞尹），遗书招降。

**决策**："妾辱之，子杀之，身为忠臣，义不顾妻子也。"

**结果**：养甲杀其妾及二子。

**分析**：
- 这不是冲动——邦彦有充分的时间权衡
- 他用"义"这一个字消解了最深刻的人伦困境
- 此前他组织乡兵保护家乡父老、赈济灾民——他对"陌生人"充满关怀
- 但在"忠"和"家"之间，他没有犹豫
- 这不是冷酷——他把"忠"视为更大的"家"

### 决策7：广州之战（1647年七月）——复杂的协同作战

**决策**：
1. 约杨可观、杨景烨为内应
2. 说花山盗三千人伪降守东门
3. 约陈子壮分两路会攻广州
4. 定于七月七日三鼓攻城

**结果**：陈子壮提前两日攻城 → 间谍被捕事泄 → 内应被杀 → 花山盗三千人被杀 → 邦彦火攻虽胜但后军溃败

**归因分析**：
- 直接原因：陈子壮提前行动 + 传令不及时
- 深层原因：各路义军缺乏统一指挥和纪律约束
- 邦彦的谋略本身没有问题（火攻战术成功"焚其巨舰数十，斩首千余"）

### 决策8：清远最后一战（1647年九月）

**决策链**：
- 收余兵转攻三水、高明，复之
- 鏖战新会香山间，一月十余捷
- 清远指挥白尝灿举城迎 → 邦彦率兵赴之
- 四会、韶州、连州翕然响应

**结果**：再次被李成栋击败，城破巷战，颈被三刃，赴水被执。

**最后行为**：
- 题诗朱氏园壁
- 被执至广州，不降
- 狱中五日不食，端坐赋诗
- 九月二十八日被杀，临命歌后向西稽首受刃

## 决策模式分析

### 邦彦的决策特征

1. **信息先行**：所有重大决策前都有充分的观察和分析（"临西江口，望见敌人旌旗"）
2. **不依赖权威**：苏观生不听？换一种方式再试。朝廷不用？自己干。
3. **行动成本自己承担**：每一个建议后面都跟着"愿以委邦彦"
4. **结果不确定时，用价值观做决定**："成不成天也，敌不敌势也"——这是他的终极决策算法
5. **复盘但不悔**：临命歌"书生漫谈兵，时哉不我兴"是复盘，"崖山多忠魂，后先照千古"是超越

### 言行一致性

| 言论 | 行动 | 一致性 |
|------|------|--------|
| "不报国，非丈夫也" | 辍讲业，北上献书 | ✓ |
| "成不成天也" | 起义失败后继续战斗 | ✓ |
| "义不顾妻子" | 妾与二子被杀，不降 | ✓ |
| "耻以空言" | 所有文章皆为应用文 | ✓ |
| "我不必收功于东而收功于西" | 牵制清军数月无西，桂林得全 | ✓ |

**高度一致**——甚至可以说是惊人一致。没有发现明显言行不一的案例。

### 失败决策

1. **对协同作战过于乐观**：广州之战过度依赖多方精确配合（内应+伪降+分路进攻+定时），任何一个环节出错都会连锁崩溃
2. **兵力组织不足**：义军"乌合之众"，缺乏训练——邦彦自己知道这一点但没有有效解决
