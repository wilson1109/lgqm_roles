# 05-decisions — 决策记录与行动

## 小说中的关键决策（35岁·当前）

### 决策1：去五仙观参加崔道长沙龙（第06章提及）
- **背景**：髡贼入城后，崔汉唐在五仙观搞沙龙聚会
- **行动**：去了，观察了热气球、显微镜，听了天文地理
- **结果**：没被"蛊惑"——元老院自己承认"没把黎掰过来"
- **逻辑**：他不是回避新知识的人——他要去亲自看看敌人到底有什么本事

### 决策2：加入反髡议事核心圈（第05-07章）
- **背景**：陈子壮召集密会
- **行动**：积极参与，成为发言最多的核心成员
- **贡献**：提供髡贼情报（五仙观沙龙、杭州复社网络、澳洲货辐射范围）
- **逻辑**：以陈子壮为师，以反髡为义不容辞

### 决策3：公开批判地圆说（第06章）
- **背景**：陈子升被澳洲天文学吸引
- **行动**：长篇论证地圆说=颠覆天尊地卑=无君臣上下
- **逻辑**：先从理论上拆解，再以师长辈身份温和安抚陈子升

### 决策4：串联复社情报（第07章）
- **背景**：陈子壮问"复社中是否有人与髡贼往来"
- **行动**：一步步回忆→"恍然大悟"——杭州完璧书社是澳洲据点，黑船到过杭州
- **结果**：拼出髡贼全国触须网络图（广州→京师→苏杭→琼崖）
- **逻辑**：他是唯一拥有跨地域情报拼图能力的人（复社名册+个人游历+敌报阅读）

### 决策5：拒绝被转化（第08章隐含）
- **背景**：去过五仙观、读过髡贼报纸、内心承认髡贼有治事之才
- **行动**：立场不动摇。心里想过"倘若当今圣上也用这套办法……"→自己掐灭
- **逻辑**："圣上乃是与士大夫共天下"——体制内改良不可能，但背叛体制他也不干

### 决策6：鄙视吕易忠（第07章）
- **背景**：吕易忠曾是王尊德幕僚，降髡后成刘翔左膀右臂
- **行动**："哼……无耻之辈，他还有脸来见老师！"
- **逻辑**：变节不可原谅——这是他与陈邦彦、邝露的共识

## 历史中的关键决策（已发生/性格已定型，部分在小说时间线之后）

### 决策A：终身断肉（1629，28岁·已发生）
- 父卒→守丧三年断肉→丧毕仍断→终身
- 逻辑：父亲喂他鱼头腹肉的童年记忆→"至今言之犹痛苦于心"
- **小说中已存在此性格底色**

### 决策B：拒官守孝（1637，36岁·即将发生）
- 陈子壮保举→以母在辞不受
- 逻辑：孝先于仕——和断肉是同一套价值体系

### 决策C：五上公车不第而不改其志（1628-1640，27-39岁）
- 五次会试全不第，但每次都继续考
- 逻辑：科举失败不等于自我否定——诗文名满天下，易学自成一家

### 决策D：黄牡丹状元（1640，39岁·未来）
- 扬州影园赋黄牡丹诗十首→钱谦益推为第一
- **小说中尚未发生，但诗才已具备**

### 决策E：罄产制军火+援赣殉国（1644-1646，43-45岁·未来）
- 甲申变后捐全部家产铸铁铳五百函
- 隆武授兵部主事，募水师援赣
- 守城月余，城陷巷战，中三矢坠马，骂不绝口而死
- 弟遂琪、仆从三十余人同日死
- **这是他人格的最终表达——但种子已经在35岁的他心里**

## 决策模式特征

| 维度 | 表现 |
|------|------|
| 第一驱动 | 儒家伦理（天尊地卑/君臣上下/由孝立忠） |
| 信息获取 | 亲身观察+跨地域人脉网络+阅读敌报 |
| 对敌态度 | 承认敌人优点+立场不动摇 |
| 对友态度 | 师事陈子壮+引出陈邦彦+安抚陈子升+鄙视吕易忠 |
| 自我矛盾 | 知道髡贼能治好国家+知道体制不能改+选择站在体制一边 |
| 核心原则 | 不可动摇的底线（不变节/不剃发/不承认髡贼正朔） |
