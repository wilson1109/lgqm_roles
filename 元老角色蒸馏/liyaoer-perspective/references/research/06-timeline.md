# 06-timeline — 人物时间线

## 来源：《临高启明》第5/6/8卷（265处提及）

## 时间线

| 阶段 | 事件 |
|------|------|
| 穿越前 | 财经口会计。不喜欢。爱好园艺和料理 |
| 穿越后早期 | 转农委会。任总会计师。搬到农场住。与梅法结婚 |
| D+? | 济州岛——随平秋盛/黄骅出差。推土豆种植和脱毒种薯繁育 |
| D+? | 杭州凤凰山庄——蚕种场、催青室、蚕桑生产队、训练班、缫丝厂。化名"跟前人"。收沈苏沈杭为徒 |
| D+? | 返回临高。沈苏沈杭入芳草地蚕桑职业班 |
| D+? | 广东/香山——天地会派往珠三角。选香山南沙建推广所。选址失误 |
| 小说现在 | 南海/九江——与张枭搭档。考察桑园围。计划建蚕桑改良基地和农业技术学校 |
