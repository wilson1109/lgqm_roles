## 完整时间线

|------|------|------|------|
| 穿越前 | D日前 | 21岁，行政管理专业本科。军史爱好者。户外运动经验。 | 第3卷 |
| D日 | 穿越 | 与众人一同穿越。 | 第3卷 |

| 杜雯手下 | 约D+2年 | 民政委员会社会工作处"调研员"（实际上是办公室打杂）。处长杜雯，副处长董薇薇。杜雯每天6点到0点工作，午木被迫奉陪，叫苦不迭。 | 第3卷 |
| 全体大会发言 | 约D+2年 | 第339节辩论。公开支持对元老的四条死罪（叛乱/叛变投敌/分裂/严重危害社会秩序）。引起争议——单良/孙立一伙威胁要"用元老的铁拳教育他"。但也引起了赵曼熊的注意。 | 第3卷 |
| 被招募 | 约D+2年 | 赵曼熊亲赴办公室秘密招募。午木接受。萧子山发出调令。"去赵曼熊斯基那里好好干吧。" | 第3卷 |
| 政治保卫总局办公室主任 | D+2—D+4年 | 协助赵曼熊组建政保总局。主管学员队政治学习。编《篡明暴行录》。建立十人团网络。处理杨草心理审查。提出充实内务部队（被赵曼熊否决）。 | 第3卷 |
| 赖大案 | 约D+3年 | 初晴旧识赖大潜入临高。午木抓捕后抽掉涉及初晴的婚约供词，向吴南海保密。请示赵曼熊后归档原始件。 | 第4卷 |
| 魏岚铎（兰度）案 | 约D+3年 | 主张监控而非抓捕——"切断了藤，我们就摸不到瓜了"。后兰度被安排去马尼拉。 | 第4卷 |
| 蓬莱演习/发动机行动 | 约D+3年 | 代赵曼熊出席蓬莱1631情报安全联席会议。面无表情。观察元老军官变化。 | 第5卷 |
| 琼山策反汤允文部 | 约D+3年 | 秘密赴琼山海口所城外工作站，亲自指挥对汤允文部的瓦解行动。 | 第5卷 |
| 济州3.15/3.20案 | 约D+3年 | 幕后遥控。给刘富卿指示"听从冯首长的指示"。 | 第5卷 |
| 港海巡64号案 | 约D+3年 | 亲自接待陈海阳，带其查阅船员档案。判断"叛变的可能性不大，很可能是被人劫持"。 | 第6卷 |
| 药物控制制度听证会 | 约D+4年 | 在秘密听证会上为里番队/粘杆处的药物控制制度作证。散发"阅后回收"报告给常委。 | 第6卷 |
| 郝元/甲事件 | 约D+4年 | 与赵曼熊深谈。多方验证郝元材料的可靠性。派陈白宾参加巡视组。与江山达成情报交换协议。 | 第6卷 |
| 女仆学校改制讨论 | 约D+4年 | 罕见公开发表意见：女仆学校应扩大而非废除——"军队和强力机关的工作人员的婚配都有缺口，人心不安"。 | 第6卷 |
| 马尼拉/黑尔听证会 | 约D+4年 | 举证揭露东南亚公司盗卖军火和航海仪器案。斩钉截铁否认有元老涉案。 | 第6卷 |
| 太阳伞专案 | 约D+4年 | 赵曼熊推导出内奸→秘密组建太阳伞专案。午木从"难以置信"到领命执行。利用文化祭安保为诱饵挖出王七索。被东方恪/冈本等元老指责"漠视元老安全"。 | 第6卷 |
| 小仓号事件 | 约D+4年 | 袭击超出预计。午木下令连夜抓捕乐工和警备营士兵，"一个不剩"。但漏网者令他担忧。 | 第6卷 |
| 调查委员会 | 约D+4年 | 被集火攻击——"谁都知道他完蛋了"，"独孤求婚第二"。赵曼熊替他改检查，叫他口头检讨不下书面稿。午木死守底线——"政治保卫局绝不能被肢解或者合并！" | 第6卷 |
| 调任广州 | 约D+5年 | 因太阳伞专案影响，赴广州任职——"很大程度上也是为了出来避风头"（张枭视角）。 | 第8卷 |
| 广州巫蛊案 | 约D+5年 | 广州分局局长/广东政保总特派员。处理刘翔"遇刺"闹鬼事件。识破刘翔撒谎但对元老不能用手段。主导内鬼案——锁定韩月→王栋→巫支祁。与崔汉唐/慕敏协作。发现石翁痕迹。公开被批评"既不知己，也不知彼"。 | 第7卷 |
| 梁存厚反宋势力案 | 约D+5年 | 监控梁府。策反内线（沉沙/珊瑚）。拼出四块拼图（招人/舆论/情报/武备）。赵曼熊到广州亲自主持"丰收"会议。午木做主题汇报。 | 第8卷 |
| 小说现在 | 约D+6年（1636） | 与张枭、文德嗣讨论岭南三忠。坚持程序正义。预判一场多省同时爆发的暴动即将来临——"一定要在暴动前，就把案子查清……不留后患的消灭干净"。 | 第8卷 |
