# 06-timeline：陈海阳行动时间线

> 本时间线按原著章节与明确的时间标记整理；章节顺序比现代年份更可靠。涉及“陈海洋”的两处均作为陈海阳异写处理。

| 时间/阶段 | 原著节点 | 事件 | 对思维的影响 |
|---|---|---|---|
| D+1 前后 | 《第十四节 侦察队》 | 参与军事组执勤方案调整，并接受非执勤时间参加劳动的安排 | 说明他一开始就是把军务放入整体人力约束，而不是拥有独立资源的职业军官 |
| 产业迁移期 | 《第四十四节 新农庄（一）》 | 从渔业组出发，向执委会申请建立兼营捕鱼的海军 | 形成“先有组织和船，再扩大舰队”的建军起点 |
| 早期海军 | 《第六十一节 发动群众（四）》 | 运送粮食、布匹、武器和建筑材料；在盐场无火器时建议队列与体能训练 | 建立运输、民兵训练和地方动员的最低可执行标准 |
| 早期近海治安 | 《第九十七节—第九十八节 海军/第一次临高角海战》 | 以捕鱼、护渔和巡逻维持海上秩序，经历海盗伏击 | 以速度、机动力、距离和平台防护做战术判断，并承认海军的物质基础限制 |
| 航海教育期 | 《第二十七节—第二十八节 航海学/昌化到了》 | 学习和教授象限仪、六分仪、经纬度与古代航海技术 | 把现代海军知识翻译成可制造、可训练的本时空技术 |
| 海南拓展期 | 《第三十七节—第四十节 来到榆林/榆林堡》 | 与王洛宾分工，负责榆林堡、矿石运输、船队通信与驻外风险 | 认识到根据地建设需要堡寨、补给、人员和纪律同时成立 |
| 海军正规化期 | 《第一百零九节—第一百一十五节》 | 招募渔民、建立本地造船线，承担海军军政岗位和发动机行动司令职务 | 由船队头目转为制度化军令干部，开始管理规模、后勤和组织关系 |
| 大屿山行动 | 《第一百四十九节—第一百五十八节》 | 进入香港、大屿山，接见海盗使者，完成海陆包抄与港岛哨所建设 | 形成“摆出国家权威—盘点投效资源—保留谈判出口”的对外作战方式 |
| 珠江口行动 | 《第一百六十三节—第一百九十一节》 | 测量航道、夺取虎门、建立补给线、征收合理负担、以炫耀武力和宣抚逼近广州 | 把海战、占领、民政、谈判和政治保卫放入同一战区框架 |
| 海军扩张与吸收 | 《第一百七十四节—第二百一十节》 | 清剿海盗、吸收诸彩老残部、分配船只、评级发饷、严格训练 | 形成“航海技能可吸收，组织纪律必须重造”的军队建设方法 |
| 造船和工业约束 | 《第一百九十七节—第一百九十八节》 | 发现小型特务艇吨位、火炮、凿船虫和维护问题，要求大吨位长用船 | 从战术胜利转向舰队规模、维护和工业能力的长期计算 |
| 军令位置固定 | 《第三百五十五节 人事异动》及《第一百一十三节—第一百一十五节》 | 由海军人民委员改任海军军令部部长 | 其核心身份落在军令系统，不是单纯军政首长或地方行政长官 |
| 大洋舰队筹建 | 《第二百五十二节—第二百五十七节》 | 讨论发动机、风帆特务艇、明秋任职和远海自持力 | 对新舰队保持专业期待与明确不确定性，强调责任和岗位名称一致 |
| 后期远海与风暴 | 《第四百四十一节—第四百五十一节》 | 参与马尼拉航线、远海拦截、风暴返航与舰船损失处理 | 接受行动有损失，但要求从航线、天气、整备和人员能力吸取教训 |
| 安全调查期 | 《第十一节—第十二节 劫持/小琉球岛》 | 处理港海巡失踪，调阅政治保卫与船员档案 | 在专业分工之外亲自追查关键事实，形成军令负责人的安全底线 |

## 时间线结论

陈海阳的变化不是从“好战”到“谨慎”，而是从“有船就先把海军办起来”逐步转向“舰队规模、补给、维护、人员训练、地方政治和远海风险必须一体化”。他一直愿意行动，但行动前后都要问：这支队伍能不能执行，海军能不能承受，元老院能不能为后果负责。
