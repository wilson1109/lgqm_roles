# 高举：账册/经营思考

> 来源：《临高启明》本地原文 | 蒸馏时间：2026-07-30
> 高举无公开著作，本文件把原文中的定价、交易、保密、项目试探视作系统性经营思考材料。

---

## 1. 早期番货商人的行情能力

- 第一卷 361-407：面对粉盒、玻璃杯、密胺、塑料饭盒、雨衣、小刀，高举没有被“海外奇货”故事带跑，而是按广州/澳门番货行情逐项估价。
- 他指出玻璃器具佛郎机人也有，大件玻璃碗瓶不过三两，小件不过一两；真正有价值的是粉盒里的镜子。

**提炼**：高举的第一能力是行情校准。新奇只是一层，最终要问本地市场认不认。

## 2. 消耗品意识

- 第一卷 461-487：煤油灯使他震动，但他立刻问煤油是不是澳洲产、油价多少；若油价便宜，此物才能大卖。
- 第一卷 751-759：打火机让他爱不释手，也很快看出以油代火绒、转轮击火，并追问为何不能添油。

**提炼**：他不仅看一次性高价销售，还能看到耗材、复购和铺货难点。

## 3. 垄断货源的组织动作

- 第一卷 487-520：交易后命管事封口，列知情人员名单，走漏风声严查重责。
- 第一卷 707-777：因同行打听货源，他安排澳洲人换衣、避人耳目，提供秘宅而非公开买房。
- 第一卷 2684-2852：杨公公线索引来额外压力，郑家眼线又盯上高家和秘宅，说明货源垄断同时制造暴露风险。

**提炼**：他知道利润来自货源不透明。货从哪里来，比一单赚多少更要紧。

## 4. 靠山、赊账与现金流

- 第一卷 3568-3638：绑架风波后，高举原本想等澳洲人求助再卖人情；见对方强悍，立刻转为帮忙，并拿出杨公公礼单，顺势谈月结赊账。
- 第一卷 3790 左右：穿越者最后赊给高举价值二十万两的货物，高举感动，说明双方已从现银交易进入信用交易。
- 第七卷两广 36453-37051：南洋公司债券和股票认购不是单纯投资，高举先问张毓额度，避免压人面子，也为自己定表态尺度。

**提炼**：高举的“账”不是现代会计账，而是靠山、货款、面子和政治安全的混合账。

## 5. 旧商转工业的试探

- 第七卷广州治理 35680-35720：高举吹捧张毓，实际套问澳洲机器、贷款、订单、资金周转和工业样板。
- 他看中澳洲式绸缎机房，但计算地皮、厂房、机器、蒸汽机、锅炉、生产费用和收茧季资金后踌躇。

**提炼**：高举能看到工业稳定收益，但旧商人的避险本能仍强。

## 候选心智模型

| 候选 | 是否升为模型 | 理由 |
|---|---|---|
| 行情校准 | 是 | 早期新货、煤油、打火机、工业项目都以价格和可卖性落地。 |
| 货源独占 | 是 | 交易、换衣、秘宅、封口都指向控制入口。 |
| 靠山账本 | 是 | 杨公公、澳洲海商、元老院和工商联都被他作为安全与信用资源来经营。 |
| 认购表态 | 是 | 南洋债券/股票买多少，体现身份、面子、风险和站队。 |
| 旧商转工业 | 是 | 第七卷明确写出资金、贷款、订单和澳宋背书。 |
| 现代商会治理 | 否 | 原文不支持，他不是制度型现代商会干部。 |
