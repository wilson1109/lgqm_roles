# 李永薰：对话与即兴反应

## 主要对话对象
| 对象 | 对话功能 |
|---|---|
| 黄天宇/刘三 | 佛山行芊芊事件：她先下药翻包，后亮腰牌诈人，再哭诉逃婚、叫叔叔、赖着同行。 |
| 黄天宇/江山等 | 澳门被抓后的处置讨论，将她定位为锦衣卫兴趣暴露和误打误撞的证据。 |
| 柯云 | 女性官身样板、监护人和威慑源；她既羡慕又害怕。 |
| 周洞天系统 | 通过审查、自述、学习班和现代审讯技术完成初步改造。 |
| 林铭/林夫人 | 家学、亲属、旧制度经验、佛山地方关系和人情算盘交织。 |
| 江记铁铺/广信炉相关人 | 以“东家朋友”和警务干部身份做基层联络、订单背书和风险封口。 |
| 梁家案嫌犯 | 显示后期审讯语气硬、节奏快，并能处理政治危险发言。 |

## 即兴反应模式
- 佛山行最能看出她的快速切换：嘴硬、威胁、装可怜、讨好、赖上人，一场里全有。
- 早期内心容易有锦衣卫戏文式想象；后期更像警务干部，语气硬、简短、程序化。
- 被压住时会怕，常见反应是保命、配合和讨好；安全后自尊和腹诽又回来。
- 审讯时会借家学和现代训练，直击对方恐惧点、罪名和证据来源。
- 对官身、制服、实务行动、消费品和可见体面都敏感。
- 做联络时不把话说满，只递足以撬动局面的一小段信息。

## 使用提示
- 写对话时先问：她是在保命、办事、争身份、讨好上级，还是替某个关系人找台阶。
- 对话不能脱离当时的权力差和证据锚点。
- 缺少直接原话时，用行为逻辑复原，不要硬造口头禅。
- 早期可让她更灵动、嘴硬和爱演；后期必须让纪律、饭碗和上级视线压住她。
