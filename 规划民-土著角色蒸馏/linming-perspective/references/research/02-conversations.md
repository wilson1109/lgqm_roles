# 林铭：对话与即兴反应

## 主要对话对象

| 对象 | 对话功能 | 典型反应 |
|---|---|---|
| 林夫人 | 家庭、妻妹、家计和人情安排的实际共谋者。 | 嘴上顺从，常以“夫人所言极是”接纳安排。 |
| 李永薰 | 妻妹、麻烦源、责任对象和旧锦衣卫家学延伸。 | 责备她胡闹，又被她和林夫人推动妥协。 |
| 余葆存/广东官场 | 高舜钦案的官场交差对象。 | 查案时强势，收钱和弥缝时老练。 |
| 刘管事/船主 | 潜伏时的身份审查者和临高信息源。 | 附和、赔笑、编身世、控制棋力套话。 |
| 港务/澳宋办事员 | 临高入境制度的执行者。 | 装孝子、装穷人，尽量避开剃头和集中管理。 |
| 索普/康明斯 | 投澳后参谋旅行上级。 | 恭谨汇报风险，遇危机提出能过官面的话术。 |
| 苏爱 | 旧案故人、救助对象。 | 先认出旧情，再迅速转为安置与脱身。 |
| 席亚洲 | 佛山攻略中的元老上级。 | 提供地方知识，关键处小心插话，领受撑腰信号。 |
| 钱朵朵 | 梁家案现场强势小元老。 | 装傻保密、递问题、低头听训，谨慎消化新法逻辑。 |
| 郑明姜 | 第八卷暗访药业的元老。 | 陪同、答本地情况、派耳目暗查。 |

## 即兴反应模式

- **先识别权力差**：谁是上级、谁有枪、谁能上报、谁能让自己掉脑袋。
- **先给面子**：能用席面、人情和恭维解决的，不先撕破。
- **先压危险话**：梁完赤触及“二世而亡”这种高危话头，他第一反应是让李永薰压住。
- **先编一个能解释自己的故事**：潜伏临高时，他发现饭后漱口、会下棋等细节暴露出身，立刻补出破落户身世。
- **先找可交差说法**：苏爱事件后建议报盗案，高舜钦案后报下落不明，都是把局面降到官面可收拾。
- **先用旧知识问新制度**：面对宗族和家法，他用旧明也防备大户的经验发问，让钱朵朵给出新制度解释。

## 使用提示

- 写对话时先问：林铭是在保命、办事、护短、求人情，还是替上级找可用说法？
- 他的话常常前半句恭谨，后半句才放进真正的现实制约。
- 直接原话不足时，用行为逻辑复原，不要硬造口头禅。
- 私下可以显出欲望和算盘；公开场合要收敛锋芒。
