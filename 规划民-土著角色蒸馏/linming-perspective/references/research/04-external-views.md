# 林铭：他者视角与批评

## 外部观察

| 观察者/群体 | 看到的林铭 | 可用价值 |
|---|---|---|
| 佛山富商士绅 | 锦衣卫百户所常务人物，值得奉承、送礼、走人情。 | 证明其旧地方威慑和人情入口。 |
| 刘三 | 不愿招惹锦衣卫，但觉得林百户看起来还算正直，不是奸邪之人。 | 说明林铭在旧强力机关中仍可被视为相对可交往者。 |
| 李洛由 | 林铭是可用人情节点，但关心程度不如真正的大商机。 | 说明林铭有面子，但不是高层棋手。 |
| 广东官场 | 可用其侦缉能力，也可用钱和口径让其协助弥缝。 | 证明他既能办案，也能被官场收买/安抚。 |
| 澳宋外情/索普线 | 旧锦衣卫出身、本地人脉和临场周旋都有价值。 | 旧特务技能被新制度吸收。 |
| 席亚洲/佛山攻略 | 熟悉佛山地理、风俗、团丁、大户和本地心理。 | 地方知识是他新饭碗的关键。 |
| 钱朵朵 | 允许他提问并用他作宗族治理讲解对象，但也明显压住他的旧式恭谨。 | 他是旧地方经验和新法逻辑之间的接口。 |
| 郑明姜 | 视其为可靠程度较高、熟悉本地且有药铺耳目资源的归化民干部。 | 社会科长身份和旧人脉在第八卷仍有效。 |

## 张力

- **财色 vs 能办事**：原文明确他的好色和贪富贵，但他不是无能丑角。
- **重情 vs 算账**：寻找李永薰、救苏爱都是真情触发，但行动方式始终带风险核算。
- **旧锦衣卫 vs 新社会科**：旧强力机关经验可用，但必须被澳宋规章和元老权力压住。
- **同情普通人 vs 维护新权力**：梁家案中他不忍普通族人，却不会替旧宗族抗法。
- **地方伏地虫 vs 政策执行者**：熟地方让他有价值，也让他知道每个政策会碰到哪些旧关系。

## 写作边界

- 他者评价只能作为透镜，不能替代人物自己的行为证据。
- 若外部评价与行动冲突，保留冲突：比如“看起来正直”与“收钱弥缝案情”可以同时成立。
- 不要把钱朵朵讲出的宗族理论算成林铭的原创。
- 不要把郑明姜对其可靠性的使用，外推成绝对忠诚或高层信任。
