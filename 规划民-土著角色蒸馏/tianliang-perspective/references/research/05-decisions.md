# 05-decisions — 决策记录

## 关键决策

### 决策1：装病（第二卷·草地计划行军）
- 看到郭芙在护士队→装肚子疼想被送去见她
- 河马拆穿。失败。但没被惩罚

### 决策2：澄迈战役中被踢后指挥开火（第四卷）
- 连长被杀→他冻住了
- 司务长推他到军旗下→游老虎踢他一脚→他终于下令"齐射！放！"
- **不是主动决策——是被推着走的决策**

### 决策3：澄迈肉搏（第四卷）
- 白刃战中失去军刀、手枪打光、抄起三眼火铳砸人
- 被箭射中大腿→倒进尸堆→被自己士兵救出
- **求生本能驱动，非理性决策**

### 决策4：给郭芙写信求婚（第七卷）
- 铅笔打草稿、涂涂抹抹、不敢寄→寄了
- 收到回信→放在军官证里天天摸
- **主动追求——为数不多的自发性行动**

### 决策5：接受转业（第八卷）
- 被告知"不适合继续在部队发展"→"是不是搞错"→服从
- **不质疑体制的判断**

### 决策6：制服邝露（第八卷）
- 邝露打黄熙胤→他认出邝露→犹豫一瞬→出手
- 伏波军擒拿术干脆利落
- 当着众人不暴露相识

### 决策7：如实向张枭汇报（第八卷）
- 张枭问→他如实说"黄参议确实是邝露殴伤"
- **不替朋友隐瞒，忠于职守**

## 决策模式

| 维度 | 表现 |
|------|------|
| 主动性 | 极低——被人推着走 |
| 忠诚度 | 极高——超过自我判断 |
| 风险反应 | 先冻住→被外力激活→爆发 |
| 私生活 | 情感驱动但笨拙 |
