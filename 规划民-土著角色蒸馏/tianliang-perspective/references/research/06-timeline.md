# 06-timeline — 人物时间线

## 来源
《临高启明》第二、三、四、七、八卷

## 完整时间线

| 时间 | 事件 |
|------|------|
| D-？| 生于北方（具体不详）。饥荒中成孤儿。与郭三娘（后郭芙）一同流浪乞讨 |
| D-？| 腿伤溃烂，走方郎中割腐肉救命。郭三娘照顾他数月。瘸了几个月 |
| D-？| 被穿越集团买走→博铺检疫营40天净化 |
| D-？| 登记时张兴教应名"田大"→元老随口"叫田凉好了" |
| D+1年 | 军政学校学兵（15岁）。笨，被教官揍。步兵科。阮小二/小五/小七去海军 |
| D+2年 | 下士班长。考核垫底 |
| D+3年 | 澄迈大战前升少尉。连《步兵操典》都背不下 |
| D+3年 | **澄迈大战**：代理连长→肉搏→负伤→被救。中尉 |
| D+5年 | 升上尉（靠资历）。第10营战列3连连长 |
| D+5年 | **北伐东路军**（潮汕）。掉护城河→肺炎→战地医院→遇侯清→与郭芙重逢→分手→痛哭 |
| D+6年（现在）| **转业**。南海国民示范学校校长兼县督学。招生困难。制服邝露。九江建校任务 |
