# 梁存厚：对话与即兴反应

## 主要对话对象
| 对象 | 对话功能 |
|---|---|
| 郭逸 | 早期在人市谈买人、救济和广州官绅风险，形成广州站可利用的士绅接口。 |
| 黄禀坤 | 从“讲髡学”转为反髡情报与外联工具；梁存厚借他理解临高，也试图让他把广州消息送出。 |
| 玉源社士子 | 早期是髡学讨论社，后期成为反髡舆论场和文底来源。 |
| 乔岩/云霆线 | 呈现武底和湿活线：藏匿、护送、反侦查、必要时灭口。 |
| 月婉 | 临败前的私密倾诉对象，呈现政保逼近、布局将败、道统不能绝和慷慨赴义。 |
| 梁元福等梁府内线 | 通过政保策反口供呈现梁府内宅、天情广闻录和梁家隐秘。 |
| 刘铩/木石道人线 | 通过审讯侧面呈现梁存厚与石翁集团、武班底、暴动计划的连接。 |

## 即兴反应模式
- 早期对澳洲人保持文雅试探，先问身份、目的、风险，再递名帖或合作。
- 玉源社阶段常把髡学问题放回圣教、名教、华夷和富强术框架里。
- 反宋阶段更少清谈，更多谈如何传消息、编书、藏人、串联、等待时机。
- 乔岩场景里会把公开财报、铁路、专业分工和“系统”都当作髡情分析对象；这是直接自述，不只是政保推断。
- 月婉场景里不再只是策略讨论，而是政保压力下的末世气节表达。
- 私下独白能承认澳宋系统、专业、财报和铁路中有强大秩序，但结论是必须制髡。
- 被政保视角呈现时，他的关键词不是“好奇”，而是“隐忍”“重点监控”“老泥鳅”“反宋势力后台”。

## 使用提示
- 写对话时先问：这是早期合作场、髡学讲学场，还是后期敌对密议场。
- 后期对话不能只写“中体西用”，必须让其服务反髡：知髡情、聚士绅、护文底、蓄武底。
- 对话不能脱离当时的权力差、政保压力和证据锚点。
- 缺少直接原话时，用行为逻辑复原，不要硬造口头禅。
