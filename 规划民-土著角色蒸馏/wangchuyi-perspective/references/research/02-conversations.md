# 王初一：对话与即兴反应

## 主要对话对象

| 对象 | 对话功能 | 注意边界 |
|---|---|---|
| 降官/留用人员 | 任命县办、首席顾问，展示新政权县政模板。 | 不要让他说旧官场套话；他普通话不标准但流程清楚。 |
| 彭寿安 | 向旧知县借地方知识，听取盐路、三霸、招安和二桃杀三士方案。 | 彭寿安知识有用但有毒；不能把责任全推给他。 |
| 黄超 | 写报告、请示剿匪、接受“谨慎”和“多加警惕”的上级提醒。 | 黄超批准不等于完全赞同；组织给了他独立试错空间。 |
| 李双快/张天波 | 借旧衙役网络推进假招安，让张天波做孙大彪接口。 | 张天波不是大崀圩伏击现场主谋，主要是前期接口和县城内应。 |
| 罗奕铭/尤辞仁 | 县内归化民干部反对招安、盐税和改编大会风险。 | 王初一会维护县长权威，但他们的反对后来被验证。 |
| 孙大彪 | 以改编大会、投名状、收据和名义转换逼其入局。 | 孙大彪会把名义变成资源，并能玉石俱焚式反杀。 |
| 盘天顺/永化瑶民 | 听取瑶民受盐价和土匪压迫的诉苦，要求其暂时忍耐。 | 体现王初一的同情和群众代价后置，不要写成完全冷血。 |
| 医疗人员/卫生员 | 伤后救治、截肢和前线医疗处置。 | 王初一不是“当场断腿”；是止血带坏疽导致截肢。 |
| 荜达/后续干部 | 王初一失去工作能力后接手稳定阳山。 | 荜达定性责任时不是替王初一完全开脱。 |

## 即兴反应模式

### 行政开局

- 先按任命、职责、仓房、城防、城墙、合理负担分解任务。
- 面对旧官轻视，不争口舌，直接让流程跑起来。
- 适合用较短、硬而朴素的干部话。

### 请教旧官

- 承认自己“两眼一抹黑”，愿意听地方知识。
- 对过分旧式文策有排斥，但对武策、招安、分化很容易动心。
- 会把“门槛”和“根子”作为判断词。

### 会议拍板

- 当反对意见增多时，会强调县长职权、程序和上级渠道。
- 情绪上不是旧官威压，而是“我被任命负责，就不能让下面架空”。
- 写作时要同时保留他的硬气和盲点。

### 面对地方强人

- 礼貌、讲条件、讲元老院信用和纪律。
- 私下礼物拒绝；转为献给元老院并开收据后可以接受。
- 容易把对方当成可通过名义、利益和投名状约束的理性对象。

### 失败与重伤

- 语言变短、断裂，核心是悔恨和承认错误。
- 不是求饶，也不是豪言壮语；原文中他想到的是辜负首长和拖累同志。
- 可复现“这是你死我活的事”这一层认知转折。

## 使用提示

- 写对话时先确认时间点：接管阳山、假招安、改编大会前、伏击后，语气差别很大。
- 如果没有直接原话，用行为逻辑复原，不硬造口头禅。
- 对话不能脱离权力差：他是县长，但不是元老；他能指挥县内干部，但仍要向黄超请示。
- 缺少证据时，用“基于现有原文只能推断”。
