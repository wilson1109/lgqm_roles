# 06 Timeline / 人物时间线

> 来源：《临高启明》本地原文 | 蒸馏时间：2026-07-30

| 时间/阶段 | 事件 | 对人物的影响 |
|---|---|---|
| 广州社学少年期 | 与张毓、曾卷、陈识新结为少年圈，逃课看澳洲连环画、玩澳洲游戏，又嘴硬反髡。 | 形成“爱澳洲新玩意但保留旧身份体面”的矛盾底色。 |
| 旧卫所失序前 | 家中伯父是广州前卫千户，李子玉以武官世家和《武备志》见闻在朋友中占上风。 | 旧家世给他虚荣和小圈子领导权。 |
| 广州光复前后 | 张毓、陈识新接入澳洲机会，李子玉因旧差事被夺而不甘。 | 对旧上进通道失望，现实主义开始压过反髡口号。 |
| 澳洲兵入城 | 他惊惧求张毓庇护全家，随后随伯父一家逃往肇庆。 | 旧身份从优势变成危险。 |
| 西江逃难 | 伯父一家被水匪杀害，李子玉跳水逃生，在三水被澳宋收留后送回广州。 | 家破和被救成为投向新政权的断点。 |
| 返穗后 | 家人甄别后放还，家计断裂，李子玉拿招警启事劝曾卷，也自己报名。 | “求人不如求己”和“官身养家”成为行动原则。 |
| 招警初审 | 李子玉通过体检和审查，张毓、曾卷落选；他承诺照看曾卷外甥。 | 成为兄弟圈第一个强力机关入口。 |
| 万寿宫警校 | 净化、剃发、穿制服、队列处罚、警务理论和政治教育。 | 旧少爷身体和礼法习惯被新纪律重塑。 |
| 初任巡警 | 与赵贵搭档，巡街、签到、管门牌证照和垃圾粪缸，逐步熟悉管片。 | 从“吃粮当差”进入真实基层治理。 |
| 南剪子巷无头尸 | 夜巡发现无头尸，尸体消失后坚持报告；高重九、李镇国确认血迹。 | 从巡警转入刑事案视野，获得立功入口。 |
| 明女/冒家客栈线 | 帮曾卷寻回被卖外甥女，牵出冒家大案；后文称他因此立功受奖。 | 个人义气与国家打击人口贩卖合流，地位上升。 |
| 临高培训 | 被派往临高培训，见识新知识、新观念和新警务系统。 | 从本地巡警转向可培养警务干部。 |
| 回广州后 | 内传将任派出所副所长；仍做治安科科员和巡警协查，处理张毓公司涉税流程。 | 升迁期待和基层琐务并存。 |
| 刑事科探长 | 第八卷中已晋升为刑事科探长、三级指挥员，带侦察小组并处理文书。 | 正式成为广州本地警务新贵。 |
| 陈定/伪币案 | 从二百两抢劫案入手，借高重九社会经验，联想到拍花、冒家案、砷白铜和巫蛊旧案。 | 形成“街面+旧案卷+物证”的刑事判断方式。 |
| 北方亲戚来投 | 张世中、黄鹤等北方亲戚抵穗，他协助户口、报备、找房和谋生。 | 官身开始服务家族重建，也带来黄鹤线盲区。 |
| 后续名望 | 第八卷最新中，陈识新以市警察局刑警李子玉和亲戚黄鹤作为牵线信用。 | 他的身份从办案资源变成朋友商业网络的背书。 |

## 时间线边界

- 原文没有完整交代李子玉从明女/冒家案到临高培训的全部办案细节。
- “副所长”在第七卷为内部消息，后续第八卷明确他已是刑事科探长、三级指挥员。
- 伯父一家遇害和李家破败有多处回顾，但家族财产具体处置只见伯父宅邸收归国有等片段。
