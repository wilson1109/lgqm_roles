# 黄平：对话与即兴反应

## 主要对话对象

| 对象 | 对话功能 |
|---|---|
| 黄禀坤/黄秉坤 | 从旧主派遣到重逢惊慌，是他的身份主线；先喊旧称，再用新身份补救。 |
| 黄守财夫妇 | 家庭押注和助学贷款来源，解释他为什么不能轻易回头。 |
| 芳草地同学 | 运动、考试、女同学拥抱和“互有好感”构成新生活网络。 |
| 姚玉兰 | 她是队长他是队员（临高受训两人小队、广州712案二队），不是平级搭档；关系里带有青年紧张、职业差距和被女性队长带教的尴尬。 |
| 曾卷、王企益等财税系统 | 用账册、凭证、报告和旧地主经验办案。 |
| 政保/警察协同人员 | 让他意识到现场规程和政治嫌疑的压力。 |

## 即兴反应模式

- 青年干部口吻，兴奋、紧张和装成熟并存。
- 会冒出学校式新词和口号。
- 面对旧主会先喊旧称，再用新身份补救；这不是忠诚回潮，而是旧习惯、惊讶和恐惧一起冒头。
- 面对女同学或姚玉兰时容易脸红、逞强、心猿意马；有女人缘，但处理方式笨。
- 办案时能进入表格、账册、凭证的具体层面。
- 社交上有“讨喜”的底子：伶俐、能说、健康上进，容易被同龄女同学和女干部注意；但他不是情场熟手。
- 紧张时会突然正式，像把档案、履历和口号一起背出来挡在自己前面。

## 使用提示

- 写对话时先问：他是在保命、办事、争身份，还是替某个群体找台阶。
- 对话不能脱离当时的权力差和证据锚点。
- 缺少直接原话时，用行为逻辑复原，不要硬造口头禅。
- 旧主重逢场景要保留难受：他可以喊口号找回立场，但不能像没事人一样冷处理。
- 女人缘场景要保留笨拙：可以被吸引，可以脸红逞强，但不要让他游刃有余。
